Navegação no Console

Antes de clicar em "Criar recurso" pela primeira vez (Aula 9), vamos aprender o mapa: o que é cada parte da tela do portal de nuvem, para você não se perder.

Objetivo da Aula

Ao final desta aula, você será capaz de:

  • Identificar os 10 elementos fixos do portal Azure.
  • Localizar um recurso usando a busca global.
  • Usar o breadcrumb para navegar sem o botão do navegador.
  • Comparar a seleção de região entre Azure, AWS e Google Cloud.

1. Conceito

O portal Azure (portal.azure.com) é a interface gráfica onde você cria, configura e monitora recursos na nuvem — o equivalente ao "painel de controle" de tudo que existe na sua assinatura. AWS e Google Cloud têm o console deles, com estrutura bem parecida (Seção 4). A documentação oficial da Microsoft descreve 10 elementos fixos que aparecem em praticamente toda tela do portal — são eles que vamos decorar hoje.

Mapa da Tela (Wireframe)
1Menu 2Breadcrumb 4Busca global 5Copilot 6Controles globais 7Conta
8 Barra de comandos (+ Criar recurso, Atualizar, Excluir...)
9 Menu de serviço (contextual ao recurso aberto)
10 Painel de trabalho (detalhes do recurso em foco)

1 Menu do portal — navega entre serviços; tem "Criar um recurso" e seus "Favoritos".

2 Breadcrumb — volta um passo no fluxo atual.

3 Cabeçalho — barra fixa no topo com os controles globais.

4 Busca global — encontra qualquer recurso, serviço ou documentação rapidamente.

5 Copilot — assistente de IA integrado ao portal.

6 Controles globais — Cloud Shell, notificações, configurações, suporte.

7 Sua conta — troca de diretório/conta ou sair.

8 Barra de comandos — ações contextuais (ex: Criar, Excluir).

9 Menu de serviço — comandos específicos do recurso aberto (também chamado "menu do recurso").

10 Painel de trabalho — mostra os detalhes do que está em foco no momento.

2. Exemplo — Ana Procura uma VM

Ana acabou de entrar no time de TI e precisa abrir os detalhes de uma máquina virtual chamada vm-estoque-01. Veja o caminho dela pelos elementos da Seção 1:

  1. Ela entra em portal.azure.com e cai na tela Home.
  2. Em vez de procurar em menus, ela usa a busca global (4) e digita "vm-estoque-01".
  3. O resultado aparece, ela clica, e o painel de trabalho (10) muda para mostrar os detalhes daquela VM específica.
  4. À esquerda, o menu de serviço (9) agora mostra opções só daquela VM: "Visão geral", "Conectar", "Monitoramento", "Discos", etc.
  5. Ela clica em "Monitoramento" e o painel muda de novo — para voltar, ela usa o breadcrumb (2) no topo, em vez de usar o botão "voltar" do navegador.
  6. Antes de sair, ela abre o sino de notificações, dentro dos controles globais (6), para conferir se alguma operação recente falhou.
Repare: em nenhum momento Ana precisou saber "de cor" onde cada coisa fica — a busca global (4) resolve a maior parte da navegação do dia a dia.

4. O Mesmo Mapa, em Cada Console

Elemento Azure AWS Google Cloud
Menu principal Menu do portal (☰) Menu "Services" (topo) Menu de navegação (☰)
Contexto de conta/projeto Assinatura + Diretório Conta AWS Projeto (Project)
Terminal embutido Cloud Shell CloudShell Cloud Shell
Seleção de região Escolhida dentro do formulário de criação de cada recurso Seletor fixo no canto superior direito, sempre visível Escolhida dentro do formulário de criação de cada recurso
Diferença que confunde iniciantes: na AWS, a região fica sempre visível e ativa no canto superior direito — se você trocar de região ali, os recursos que aparecem na tela mudam todos de uma vez. Na Azure e no Google Cloud, a região é escolhida por recurso, na hora de criar — não existe um "interruptor de região" global no cabeçalho.

Exercício 1 — Associe o Elemento à Função

⭐

Cenário

Associe cada ação ao elemento da interface (Seção 1) que resolve ela:

  1. Voltar um passo no fluxo sem usar o botão do navegador.
  2. Encontrar rapidamente um recurso pelo nome, sem navegar por menus.
  3. Ver os comandos específicos de uma VM que você acabou de abrir.
  4. Conferir se uma operação recente deu erro.
Dica

Releia os 10 itens numerados da Seção 1.

Solução

  1. Breadcrumb (2)
  2. Busca global (4)
  3. Menu de serviço (9)
  4. Notificações, dentro dos Controles globais (6)

Exercício 2 — Reconte o Caminho da Ana

⭐⭐

Cenário

Sem olhar a Seção 2, explique com suas palavras os passos que a Ana seguiu para abrir os detalhes da vm-estoque-01 e depois voltar. Use pelo menos 3 dos 10 elementos pelo nome.

Dica

Ela não navegou por menus para achar a VM — usou um atalho.

Solução (resumo esperado)

Ana usou a busca global para achar a VM diretamente pelo nome, o que abriu o painel de trabalho com os detalhes dela. O menu de serviço mudou para mostrar comandos daquela VM específica. Para voltar, ela usou o breadcrumb em vez do botão do navegador.

Exercício 3 — AWS x Azure: Região

⭐⭐

Cenário

Um colega que só usa Azure entra no console da AWS pela primeira vez e estranha um seletor de região bem grande no canto superior direito, algo que ele nunca precisou usar na Azure.

O que fazer

Explique para ele a diferença de filosofia entre os dois consoles nesse ponto específico.

Dica

Releia o box amarelo da Seção 4.

Solução

Na AWS, a região é um contexto global sempre ativo no topo da tela — trocar ali muda o que aparece em toda a tela. Na Azure (e no Google Cloud), não existe esse seletor global: a região é escolhida individualmente, dentro do formulário de criação de cada recurso.

Exercício 4 — Complete a Frase

⭐

Cenário

Complete: "A ___(1)___ mostra ações contextuais como 'Criar recurso'; o ___(2)___ muda de acordo com o recurso que está aberto no momento; e o ___(3)___ é onde os detalhes desse recurso realmente aparecem."

Dica

São os elementos 8, 9 e 10 do wireframe.

Solução

(1) barra de comandos — (2) menu de serviço — (3) painel de trabalho.

Exercício 5 — Guia para o Novato (Boss Final)

⭐⭐⭐⭐

Um novo estagiário vai entrar no portal Azure pela primeira vez semana que vem, sem nunca ter visto essa tela antes.

O que fazer

Escreva um guia curto (5-8 linhas) explicando pelo menos 5 dos 10 elementos da interface, na ordem em que ele provavelmente vai encontrá-los ao tentar achar e abrir um recurso específico pela primeira vez.

Dica

Reaproveite a lógica do caminho da Ana (Seção 2), mas escreva como um guia, não como uma história.

Solução (exemplo de guia)

Ao entrar, você cai na tela Home. Use a busca global no topo para digitar o nome do recurso que procura, em vez de navegar pelo menu do portal. Ao clicar no resultado, o painel de trabalho mostra os detalhes dele, e o menu de serviço à esquerda muda para os comandos daquele recurso específico. Se precisar voltar um passo, use o breadcrumb no topo em vez do botão "voltar" do navegador — ele mantém o contexto certo dentro do portal.
