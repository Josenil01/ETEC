Guia do Professor

Como preparar, com antecedência, as demonstrações ao vivo no portal Azure usadas nas Aulas 9, 11, 13 e 14 — sem sustos de conta, custo ou tempo em sala.

Leia isto pelo menos 1 dia antes da aula

Todas as demonstrações deste guia envolvem criar uma conta Azure real (não é mais possível usar o sandbox gratuito do Microsoft Learn — ele foi descontinuado, ver Aula 7/9). Nada aqui é caro nem arriscado se você seguir os passos, mas precisa ser testado com calma antes, fora do horário de aula.

1 Criar sua conta Azure (uma vez só)

  1. Acesse azure.microsoft.com/free e clique em "Iniciar gratuitamente" (ou "Start free").
  2. Entre com uma conta Microsoft — pode ser uma conta pessoal sua ou uma nova, criada só para isso. Não precisa ser a mesma conta que você usa no Microsoft Learn.
  3. A Microsoft vai pedir um cartão de crédito para verificação de identidade. Isso é uma exigência de qualquer conta Azure real (Aula 7) — o cartão é só para confirmar que você é uma pessoa real, e a Microsoft não cobra nada automaticamente depois que o período gratuito acabar, a menos que você faça um upgrade manual e explícito.
  4. Ao final, você tem: US$ 200 em créditos por 30 dias + uma lista de serviços sempre-grátis por 12 meses (Aula 7).
Use um cartão que você mesmo controla (não peça emprestado a um aluno ou responsável de aluno). Se a escola tiver um convênio educacional com Azure, prefira usar a conta institucional em vez da sua pessoal.

2 Quanto isso custa de verdade?

As VMs usadas nas demonstrações são pequenas (família B, Aula 12) e ficam ligadas só durante a aula. Uma VM B1s, o menor tamanho disponível, custa menos de US$ 0,01 por hora — uma demonstração de 30-40 minutos custa uma fração de centavo, dentro do crédito gratuito de US$ 200.

Configure um alerta de orçamento (o mesmo hábito de consumo consciente da Aula 7) assim que criar a conta: procure "Cost Management" no portal, crie um orçamento de, por exemplo, US$ 5, com alerta por e-mail em 80% — assim você é avisado bem antes de qualquer valor relevante.

3 Roteiro da demonstração (Aula 13)

Este é o roteiro completo, em português, com valores prontos para digitar — não é preciso ler a documentação em inglês durante a aula (mas vale ler uma vez, sozinho, antes: link oficial).

  1. No portal, pesquise Virtual machines → Create → Virtual machine.
  2. Basics: Resource group → "Create new" → nome rg-demo-aula13. Nome da VM: vm-demo-turma. Region: a mais próxima (ex: Brazil South). Image: Ubuntu Server 22.04 LTS. Size: clique em "See all sizes" e escolha Standard_B1s (o mais barato). Authentication: "Password", usuário azureuser, senha forte anotada num papel (não precisa decorar).
  3. Inbound port rules: "Allow selected ports" → marque SSH (22) e HTTP (80).
  4. Disks: deixe tudo no padrão.
  5. Networking: deixe tudo no padrão (já vem com IP público habilitado).
  6. Management: ative "Enable auto-shutdown", horário sugerido: 1 hora à frente do horário atual (ex: se a aula é às 14h, configure 15h). Isso é sua rede de segurança caso esqueça de apagar depois.
  7. Review + create → Create. Leva de 1 a 3 minutos para ficar pronta — aproveite esse tempo para reforçar os conceitos da Seção 1 da Aula 13 com a turma.
  8. Quando pronta, clique em Go to resource → Connect → SSH — copie o comando SSH mostrado (algo como ssh azureuser@20.x.x.x) só para mostrar que existe; não precisa efetivamente conectar durante a aula, o Killercoda (Aula 13, Seção 3) cobre a prática de comandos.
Tempo total estimado: 15-20 minutos (contando explicação + espera do provisionamento). Não apague a VM ao final desta aula — a Aula 14 volta a essa mesma VM para mostrar o NSG gerado automaticamente. A limpeza definitiva acontece só ao final da Aula 14 (veja abaixo).

4 Continuando na Aula 14 (e limpando ao final)

  1. Reabra a vm-demo-turma criada na Aula 13. No menu de serviço (Aula 8), procure Networking.
  2. Mostre as regras de NSG geradas automaticamente pelo assistente (SSH e HTTP liberados) — compare com a tabela de exemplo da Aula 14, Seção 2.
  3. Ao final da Aula 14, feche o ciclo completo (Aula 11): vá em Resource groups → rg-demo-aula13 → Delete resource group → digite o nome para confirmar. Isso apaga a VM e tudo relacionado, de uma vez.

5 Plano B: se a demonstração ao vivo não for possível

Problemas de internet, projetor ou tempo acontecem. Se não der para demonstrar ao vivo:

  • Narre o roteiro da Seção 3 acima como uma história (igual ao Exemplo "Criando a vm-loja-web" da Aula 13, Seção 2) — a turma já tem esse exemplo escrito para acompanhar sem precisar ver a tela.
  • A prática individual no Killercoda (Aula 13, Passo 2) continua funcionando normalmente, mesmo sem a parte do Azure — é a parte que garante mão-na-masso real de qualquer forma.
  • Retome a demonstração ao vivo numa aula seguinte, quando o problema técnico for resolvido.
