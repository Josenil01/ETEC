Troca a fantasia pelo mundo real. Constrói um sistema bancário completo em Python — o tipo de projeto que aparece em portfólios e entrevistas de emprego.

🏦 O Projeto: PyBank

Em vez de um RPG, hoje construímos algo que qualquer empresa reconhece: um sistema bancário de terminal. O programa deve ser capaz de:

✔

Criar uma conta (Dicionários e Inputs).

✔

Depositar e levantar com validação (Funções e Try/Except).

✔

Gerar um extrato de movimentações (Listas e Loops).

✔

Guardar e carregar a conta em disco (Tratamento de Arquivos).

2. Planta do Código (Arquitetura)

Um projeto real começa com organização. Eis como vamos dividir a nossa lógica:

Dados (Estado)

  • • Conta: Dicionário {titular, saldo, historico}
  • • Historico: Lista de movimentações em texto
  • • Save File: conta.json

Ações (Funções)

  • • depositar() / sacar(): validam e atualizam o saldo
  • • extrato(): mostra o histórico de movimentações
  • • carregar_conta() / salvar_conta(): persistência em JSON

"Depositar", "Levantar" e "Extrato" voltam sempre para o Menu — só "Guardar e Sair" termina o laço while.

3. O Enunciado da Missão

"Foste contratado como programador júnior do Banco Python. O seu primeiro trabalho é construir um protótipo de terminal que qualquer cliente possa usar para gerir a sua conta — sem perder dados entre uma sessão e outra."

Nesta prova final, vamos construir um sistema bancário baseado em texto. Ao iniciar, o programa pergunta se já existe uma conta guardada; se não existir, pede o nome do titular e cria uma conta nova com saldo zero. A partir daí, o usuário pode depositar dinheiro, levantar dinheiro (sem nunca ficar com saldo negativo), consultar um extrato com todas as movimentações feitas na sessão, e por fim guardar tudo num arquivo para continuar noutro dia.

Requisitos Obrigatórios (clica para marcar o que já fizeste):

  • ✓ A conta deve ser um Dicionário contendo: titular, saldo e um histórico de movimentações.
  • ✓ As Funções de depositar e levantar devem validar os valores: nunca aceitar negativos, nunca deixar o saldo ficar negativo.
  • ✓ O programa deve rodar num laço While até o usuário escolher sair.
  • ✓ O extrato deve percorrer a Lista de histórico e mostrar cada movimentação.
  • ✓ Se o usuário digitar texto onde deveria digitar um valor, o programa deve capturar o erro com try/except em vez de rebentar.
  • ✓ Ao iniciar, deve tentar Carregar uma conta existente antes de pedir dados novos; ao sair, deve Guardar a conta num arquivo.

4. PyBank (Construção Guiada)

Vamos construir o pybank.py em 4 fases, cada uma testável isoladamente antes de seguir para a próxima.

Fase 1: Fundação e Persistência

Primeiro, as funções que leem e escrevem a conta em disco (Aula 17 e 19), protegidas com try/except (Aula 18).

pybank.py — fase 1 
import json # Persistência de dados (Aula 17 e 19)

def carregar_conta():
    # Tente ler uma conta já existente (Aula 19 + Aula 18)
    try:
        with open("conta.json", "r", encoding="utf-8") as f:
            return json.load(f)
    except FileNotFoundError:
        return None # Ainda não existe nenhuma conta guardada

def salvar_conta(conta):
    try:
        with open("conta.json", "w", encoding="utf-8") as f:
            json.dump(conta, f, ensure_ascii=False, indent=2)
        print("✔️ Conta guardada com sucesso!")
    except Exception as e:
        print(f"❌ Erro ao guardar: {e}")

Fase 2: Funções de Movimentação

depositar() e sacar() (Aula 16) validam a operação antes de mexer no dicionário da conta, e registam tudo na Lista de histórico (Aula 14).

pybank.py — fase 2 
# --- FUNÇÕES DE MOVIMENTAÇÃO (Aula 16) ---
def depositar(conta, valor):
    if valor <= 0:
        print("❌ O valor do depósito deve ser positivo.")
        return
    conta["saldo"] += valor
    conta["historico"].append(f"Depósito de R$ {valor:.2f}")
    print(f"✔️ Depósito realizado. Saldo atual: R$ {conta['saldo']:.2f}")

def sacar(conta, valor):
    if valor <= 0:
        print("❌ O valor do levantamento deve ser positivo.")
        return
    if valor > conta["saldo"]:
        print("❌ Saldo insuficiente para este levantamento.")
        return
    conta["saldo"] -= valor
    conta["historico"].append(f"Levantamento de R$ {valor:.2f}")
    print(f"✔️ Levantamento realizado. Saldo atual: R$ {conta['saldo']:.2f}")

Fase 3: Extrato

Um laço for (Aula 13) percorre a Lista de histórico e imprime cada movimentação guardada.

pybank.py — fase 3 
def extrato(conta):
    print(f"\n--- EXTRATO DE {conta['titular'].upper()} ---")
    if not conta["historico"]:
        print("Nenhuma movimentação ainda.")
    else:
        for movimento in conta["historico"]:
            print(f"• {movimento}")
    print(f"Saldo atual: R$ {conta['saldo']:.2f}")

Fase 4: Inicialização e Ciclo Principal

Primeiro tentamos carregar_conta(); só se não houver nada guardado é que criamos uma conta nova (Aula 15 e 11). Depois, o laço while (Aula 13) com if/elif (Aula 12) e try/except (Aula 18) na leitura dos valores.

pybank.py — fase 4 
# --- INICIALIZAÇÃO (Aula 15 e 11) ---
print("--- BEM-VINDO AO PYBANK ---")
conta = carregar_conta()

if conta is None:
    nome_input = input("Não encontrámos nenhuma conta. Qual é o seu nome? ")
    conta = {
        "titular": nome_input,
        "saldo": 0.0,
        "historico": []
    }
else:
    print(f"Bem-vindo de volta, {conta['titular']}!")

# --- CICLO PRINCIPAL (Aula 13) ---
while True:
    print(f"\nSaldo atual: R$ {conta['saldo']:.2f}")
    opcao = input("[1] Depositar | [2] Levantar | [3] Extrato | [4] Guardar e Sair: ")

    if opcao == "1" or opcao == "2":
        try:
            valor = float(input("Valor: R$ "))
        except ValueError:
            print("❌ Digite um número válido.")
            continue
        if opcao == "1":
            depositar(conta, valor)
        else:
            sacar(conta, valor)

    elif opcao == "3":
        extrato(conta)

    elif opcao == "4":
        salvar_conta(conta)
        break

    else:
        print("❌ Opção inválida.")
