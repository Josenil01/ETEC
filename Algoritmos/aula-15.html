Aula 15: Mapas e Chaves

Vá além das listas. Aprenda a usar Dicionários e Conjuntos para mapear informações complexas e garantir a unicidade dos seus dados.

📚 Resumo Teórico

Até agora, as nossas listas eram acessadas por números (índices). Mas e se quiséssemos encontrar a "Força" do herói sem saber a sua posição? Para isso usamos os Dicionários.

  • Dicionários (dict): Coleções de pares Chave: Valor. Perfeito para cadastros e perfis.
  • Conjuntos (set): Coleções que não permitem duplicatas e não têm ordem fixa. Ótimo para verificar itens únicos.

Nesta aula, vamos acompanhar um único herói — Arthur — do início ao fim: registamos a sua ficha num dicionário, guardamos as suas habilidades num conjunto e, no laboratório final, juntamos as duas estruturas. Também integraremos input(), if/elif/else, operadores lógicos e laços for.

1. O Livro de Registos

1a. Dicionários (dict)

Um dicionário usa chavetas {} e mapeia uma etiqueta (Chave) a um conteúdo (Valor).

Chave "nome"
Valor "Arthur"
Chave "forca"
Valor 15

1b. Conjuntos (set)

Nem tudo precisa de uma etiqueta. Um conjunto também usa chavetas {}, mas guarda só os valores — e nunca deixa um item repetido entrar duas vezes.

Porque não usar uma lista? Imagina que vai registando as habilidades que o Arthur aprende. Numa lista, nada impede que a mesma habilidade seja adicionada duas vezes:

Lista (permite repetidos) ["Bloqueio", "Cura Menor", "Bloqueio"]

3 itens — "Bloqueio" aparece 2 vezes.

Conjunto (elimina repetidos) {"Bloqueio", "Cura Menor"}

2 itens — cada habilidade só conta uma vez.

"Ataque Duplo" "Bloqueio" "Cura Menor" "Bloqueio" (repetido, ignorado)

⚠ 3 cuidados importantes com conjuntos

1. Não têm posições: não existe habilidades[0]. Um conjunto não é acessado por índice, só com in, add() e remove().

2. Não têm ordem garantida: a ordem em que os itens aparecem quando faz print() pode não ser a mesma em que foste os adicionando.

3. {} vazio é um dicionário, não um conjunto: {} sozinho cria um dicionário vazio. Para um conjunto vazio tem que escrever set().

2. Exemplos Práticos Comentados

Os seis exemplos abaixo seguem o mesmo herói, Arthur, do registo inicial até à busca de chaves e contagem de itens únicos.

01. Registar um Herói (Criar e Acessar)

ficha_heroi.py 
# Criar o registo inicial do herói
heroi = {
    "nome": "Arthur",
    "forca": 15,
    "classe": "Guerreiro"
}

# Acessar a um valor pela chave
print(f"O herói {heroi['nome']} tem {heroi['forca']} de força.")

02. Atualizar o Registo com Segurança (.get() e del)

update_heroi.py 
# Continua do exemplo 01: o dicionário "heroi" já existe
# Modificar ou adicionar um novo par ao mesmo herói
heroi["forca"] += 5
heroi["ouro"] = 100

# .get() evita o KeyError quando a chave pode não existir
mana = heroi.get("mana", 0)
print(f"Mana disponível: {mana}")

# del remove uma chave que já não precisamos
del heroi["classe"]

print(heroi)

03. Habilidades Únicas do Herói (Sets)

habilidades_heroi.py 
# Continua do exemplo 01: o dicionário "heroi" já existe
# Conjuntos usam {} mas não têm pares (:)
habilidades = {"Ataque Duplo", "Bloqueio", "Cura Menor"}

# Tentar adicionar duplicado (não acontece nada)
habilidades.add("Bloqueio")

# Verificar se uma habilidade existe (Operador IN)
if "Cura Menor" in habilidades:
    print(f"{heroi['nome']} sabe curar-se sozinho!")

# Atenção: a ordem impressa pode não ser a ordem em que os itens foram adicionados
# E não existe habilidades[0] — conjuntos não têm índice!
print(f"Habilidades: {habilidades}")

04. Combinando Dicionário + Conjunto

bonus_heroi.py 
# Continua dos exemplos 01-03: "heroi" e "habilidades" já existem
# Usar o conjunto de habilidades para decidir um bónus no dicionário
if "Cura Menor" in habilidades:
    heroi["classe_secundaria"] = "Clérigo"

# Percorrer o registo final do herói com .items()
print("\n--- FICHA FINAL ---")
for chave, valor in heroi.items():
    print(f"{chave.upper()}: {valor}")

05. Buscar uma Chave no Registo

busca_heroi.py 
# Continua do exemplo 01: o dicionário "heroi" já existe
chave_procurada = input("Que atributo quer consultar (ex: nome, forca): ")

# O operador IN também funciona em dicionários: procura nas chaves
if chave_procurada in heroi:
    print(f"{chave_procurada}: {heroi[chave_procurada]}")
else:
    print("Essa chave não existe no registo.")

06. Contar Itens de um Conjunto

contar_habilidades.py 
# Continua do exemplo 03: o conjunto "habilidades" já existe
# len() conta quantos itens únicos existem no conjunto
print(f"Número de habilidades únicas: {len(habilidades)}")

# Tentar repetir uma habilidade não aumenta a contagem
habilidades.add("Bloqueio")
print(f"Depois de repetir 'Bloqueio': {len(habilidades)}")

# Só uma habilidade realmente nova aumenta a contagem
habilidades.add("Investida")
print(f"Depois de aprender 'Investida': {len(habilidades)}")

3. Laboratório: O Criador de Personagens

Neste laboratório, usamos input para preencher um dicionário, while para recolher habilidades num set e if para validar bónus — juntando tudo o que aprendemos nos exemplos anteriores.

rpg_maker.py 
personagem = {}

# Entrada de Dados
personagem["nome"] = input("Nome do Herói: ")
personagem["nivel"] = int(input("Nível (1-10): "))
personagem["xp"] = 0

# Lógica de Bónus com IF e Operadores Aritméticos
if personagem["nivel"] > 5:
    personagem["status"] = "Veterano"
    personagem["vida"] = personagem["nivel"] * 20
else:
    personagem["status"] = "Novato"
    personagem["vida"] = personagem["nivel"] * 10

# Recolher habilidades num conjunto (sem duplicados)
# Usamos set() e não {} — {} sozinho criaria um dicionário vazio!
habilidades = set()
continuar = "s"

while continuar == "s":
    nova_habilidade = input("Habilidade (ou Enter para parar): ")
    if nova_habilidade == "":
        break
    habilidades.add(nova_habilidade)
    continuar = input("Adicionar outra? (s/n): ")

# Juntar o conjunto de habilidades ao dicionário do personagem
personagem["habilidades"] = habilidades

# Exibição Integrada
print("\n--- FICHA TÉCNICA ---")
for chave, valor in personagem.items():
    print(f"{chave.upper()}: {valor}")

💡 Dicas do Oráculo

✓ Dica 1: As chaves de um dicionário devem ser únicas.

✓ Dica 2: Use .items() num laço for para pegar a Chave e o Valor.

✓ Dica 3: Use .get("chave", valor_padrao) quando não tiver a certeza se a chave existe — evita o KeyError por completo.

✓ Dica 4: Conjuntos têm operadores próprios: | une, & intersecta, - mostra a diferença.

⚠ Erro Comum: Tentar acessar a uma chave inexistente com dicionario["chave"] causa KeyError.

⚠ Erro Comum: Escrever meu_set = {} para criar um conjunto vazio — isso cria um dict! O correto é meu_set = set().

⚠ Erro Comum: Tentar acessar a um item de um conjunto por posição, como habilidades[0] — conjuntos não têm índice.
