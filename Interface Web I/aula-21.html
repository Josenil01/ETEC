Objetos: Modelando o Mundo Real

Um array guarda uma lista. Um objeto guarda algo mais rico: várias informações relacionadas, cada uma com o seu próprio nome. Hoje fechamos o bloco "Funções, Arranjos e Objetos" com um cartão de visita digital.

1 Conceitos-Chave

Um objeto guarda pares chave: valor — cada informação tem um nome, em vez de uma posição numérica como no array.

  • const pessoa = { nome: 'Neo', idade: 25 }; cria um objeto com 2 propriedades.
  • pessoa.nome acessa uma propriedade pelo nome (também dá pra usar pessoa['nome']).
  • Um objeto pode ter métodos: funções guardadas como propriedade, que fazem algo com o próprio objeto.
  • const { nome, idade } = pessoa; — desestruturação por NOME (não por posição, como no array).

O que é this?

Dentro de um método, this se refere ao próprio objeto que chamou aquele método. É assim que um método consegue acessar as outras propriedades do mesmo objeto. Vamos ver isso ao vivo no Playground.

Objetos Aninhados & Prévia de JSON

Objeto Dentro de Objeto

Uma propriedade pode ser outro objeto — é assim que se modela informação com "camadas".

pessoa.endereco.cidade

Array de Objetos

O padrão mais comum de todos: uma lista onde cada item é um objeto completo (um produto, um usuário, um contato...).

const produtos = [{ nome: 'Mouse', preco: 45 }, ...];

Prévia: JSON.stringify

JSON.stringify(pessoa) transforma um objeto em texto. Vamos usar isso pra valer na Aula 25, quando conversarmos com APIs de verdade.

2. Exemplo Prático: Cartão de Visita Digital

Uma função (Aula 19) que devolve um objeto com um endereço aninhado e um método que usa this para se apresentar sozinho.

cartao_de_visita.html 
<style>
  .cartao {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
    background: #fff; padding: 20px; border-radius: 12px; width: 300px;
  }
  button, #resultado { grid-column: 1 / 3; } /* Aula 14 */
  #resultado { text-align: left; }
</style>

<div class="cartao">
  <input id="nome" value="Trinity">
  <input id="cargo" value="Hacker">
  <input id="cidade" value="Zion">
  <button id="btn-gerar">Gerar Cartão</button>
  <p id="resultado">Preencha os dados</p>
</div>

<script>
  // Função que MONTA e devolve um objeto (Aula 19 + Aula 21)
  function criarCartao(nome, cargo, cidade) {
    return {
      nome: nome,
      cargo: cargo,
      endereco: { cidade: cidade },       // objeto aninhado
      apresentar: function() {              // método usando this
        return this.nome + ' — ' + this.cargo + ' (' + this.endereco.cidade + ')';
      }
    };
  }

  const inputNome = document.getElementById('nome');
  const inputCargo = document.getElementById('cargo');
  const inputCidade = document.getElementById('cidade');
  const botao = document.getElementById('btn-gerar');
  const resultado = document.getElementById('resultado');

  botao.addEventListener('click', () => {
    const pessoa = criarCartao(inputNome.value, inputCargo.value, inputCidade.value);
    resultado.textContent = pessoa.apresentar();
  });
  </script>

Exercício 1 — Criar e Exibir um Objeto

⭐

O que você tem

<button id="btn-mostrar">Mostrar Pessoa</button>
<p id="saida">--</p>

<script>
  const botao = document.getElementById('btn-mostrar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Crie const pessoa = { nome: 'Neo', idade: 25, cidade: 'Zion' }; e mostre as 3 propriedades juntas no clique.

Dica

Acesse cada propriedade com ponto: pessoa.nome, pessoa.idade, pessoa.cidade.

botao.addEventListener('click', () => {

});

Resultado esperado

⭐⭐

O que você tem

<script>
  const jogador = {
    nome: 'Trinity',

  };
  const botao = document.getElementById('btn-apresentar');
  const saida = document.getElementById('saida');
  // e chame jogador.apresentar() aqui no clique
</script>

O que fazer

Adicione um método apresentar dentro de jogador, que usa this para devolver "Trinity tem 850 pontos."

Dica

Dentro do objeto: apresentar: function() { return this.nome + ...; }.

Solução

const jogador = {
  nome: 'Trinity',
  pontos: 850,

    return this.nome + ' tem ' + this.pontos + ' pontos.';

botao.addEventListener('click', () => {
  saida.textContent = jogador.apresentar();
});

Resultado esperado

Prévia

Exercício 5 — Catálogo com Array de Objetos

⭐⭐⭐⭐⭐

O que você tem

<button id="btn-listar">Listar Produtos</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const produtos = [
    { nome: 'Notebook', preco: 3200 },
    { nome: 'Mouse', preco: 45 },
    { nome: 'Teclado', preco: 120 }
  ];
  const botao = document.getElementById('btn-listar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

1. Use produtos.forEach((produto, indice) => ...) pra montar uma linha por produto: "1. Notebook — R$ 3200".

2. Use produtos.reduce(...) (Aula 20) pra somar produto.preco de todos.

3. Mostre a lista completa + o total no final.

Solução

botao.addEventListener('click', () => {
  let texto = '';
  produtos.forEach((produto, indice) => {
    texto += (indice + 1) + '. ' + produto.nome + ' — R$ ' + produto.preco + '\n';
  });
  const total = produtos.reduce((soma, produto) => soma + produto.preco, 0);
  texto += '\nTotal: R$ ' + total;
  saida.textContent = texto;
});

Checklist do Catálogo:

✔ forEach com índice pra numerar

✔ acessa produto.nome e produto.preco

✔ reduce soma produto.preco de todos

✔ lista + total no mesmo texto

Resultado esperado

Prévia

1. Notebook — R$ 3200
2. Mouse — R$ 45
3. Teclado — R$ 120

Total: R$ 3365
