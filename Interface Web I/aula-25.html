Fetch API e JSON

Chega de dados fixos no código. Hoje buscamos informação real, na internet, com um serviço que todo brasileiro já usou sem saber: a busca de endereço por CEP.

1 Conceitos-Chave

fetch(url) dispara um pedido HTTP de verdade e devolve uma Promise (Aula 24) — por isso sempre vem acompanhado de await.

  • const resposta = await fetch(url); — resposta ainda NÃO são os dados, é um objeto Response.
  • const dados = await resposta.json(); converte o corpo da resposta em objeto/array JavaScript.
  • resposta.status (ex: 200, 404) e resposta.ok (true se deu certo) dizem como o pedido foi.

O que é JSON?

JSON é só texto formatado parecido com objetos e arrays do JavaScript — mas TODA chave e string usam aspas duplas: {"nome": "Neo", "idade": 25}. É o formato universal em que APIs devolvem dados.

JSON.stringify/parse & Tratamento de Erro

Convertendo entre objeto e texto

JSON.stringify(objeto) objeto → texto
JSON.parse(texto) texto → objeto (raro — .json() já faz isso)

Dois tipos de "erro" diferentes

try/catch pega ERRO DE REDE (sem internet, servidor fora do ar). Mas um CEP inválido ainda é uma resposta VÁLIDA (200 OK) — só que com um aviso dentro do JSON. Sempre confira os dois.

2. Exemplo Prático: Buscador de CEP

Fetch de verdade na API pública ViaCEP — com tratamento de CEP inválido E de erro de rede, lado a lado.

buscador_de_cep.html 
<style>
  .painel { display: grid; gap: 10px; background: #fff; padding: 20px; border-radius: 12px; width: 300px; }
  #resultado { font-size: 13px; text-align: left; }
</style>

<div class="painel">
  <input id="cep" value="01310930">
  <button id="btn-buscar">Buscar Endereço</button>
  <p id="resultado"></p>
</div>

<script>
  const inputCep = document.querySelector('#cep');
  const botao = document.querySelector('#btn-buscar');
  const resultado = document.querySelector('#resultado');

  botao.addEventListener('click', async () => {
    resultado.textContent = 'Buscando...';
    try {
      const resposta = await fetch(`https://viacep.com.br/ws/${inputCep.value}/json/`);
      const dados = await resposta.json();

      if (dados.erro) {                     // resposta OK, mas CEP não existe
        resultado.textContent = 'CEP não encontrado.';
        return;
      }

      resultado.textContent = `${dados.logradouro}, ${dados.bairro} — ${dados.localidade}/${dados.uf}`;
    } catch (erro) {                        // sem internet, servidor fora do ar
      resultado.textContent = 'Erro de conexão: ' + erro.message;
    }
  });
  </script>
Resultado Renderizado (fetch real)

Este iframe faz um pedido de rede de verdade — precisa de internet pra funcionar. Abra o DevTools → Network se quiser ver o pedido acontecendo (Aula 13 de Web II).

Exercício 1 — Fetch de Um Usuário

⭐

O que você tem

<button id="btn-buscar">Buscar Usuário 1</button>
<p id="saida">--</p>

<script>
  const botao = document.querySelector('#btn-buscar');
  const saida = document.querySelector('#saida');
  // seu código aqui
</script>

O que fazer

Use fetch('https://jsonplaceholder.typicode.com/users/1'), converta com .json(), e mostre o nome e e-mail.

Dica

Lembre do async na função do addEventListener — sem ele, await não funciona.

Solução

botao.addEventListener('click', async () => {
  saida.textContent = 'Buscando...';
  const resposta = await fetch('https://jsonplaceholder.typicode.com/users/1');
  const usuario = await resposta.json();
  saida.textContent = usuario.name + ' (' + usuario.email + ')';
});

Exercício 2 — Listar Posts

⭐⭐

O que você tem

<button id="btn-listar">Listar Posts</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const botao = document.querySelector('#btn-listar');
  const saida = document.querySelector('#saida');
  // seu código aqui
</script>

O que fazer

Faça fetch de .../posts?userId=1 (devolve um ARRAY) e use forEach (Aula 20) pra listar os títulos, numerados.

Dica

Cada item do array tem uma propriedade .title.

Solução

botao.addEventListener('click', async () => {
  saida.textContent = 'Buscando...';
  const resposta = await fetch('https://jsonplaceholder.typicode.com/posts?userId=1');
  const posts = await resposta.json();
  let texto = '';
  posts.forEach((post, indice) => {
    texto += (indice + 1) + '. ' + post.title + '\n';
  });
  saida.textContent = texto;
});

Exercício 4 — Popular uma Tabela

⭐⭐⭐⭐

O que você tem

<button id="btn-tabela">Carregar Tabela</button>
<table>
  <thead><tr><th>Nome</th><th>Cidade</th></tr></thead>
  <tbody id="corpo-tabela"></tbody>
</table>

<script>
  const botao = document.querySelector('#btn-tabela');
  const corpoTabela = document.querySelector('#corpo-tabela');
  // seu código aqui
</script>

O que fazer

Busque .../users e, pra cada usuário, crie uma <tr> com createElement (Aula 22) mostrando nome e usuario.address.city (objeto aninhado, Aula 21).

Dica

Cada linha precisa de 2 <td> dentro dela, adicionados com appendChild.

Solução

botao.addEventListener('click', async () => {
  const resposta = await fetch('https://jsonplaceholder.typicode.com/users');
  const usuarios = await resposta.json();
  usuarios.forEach((usuario) => {
    const linha = document.createElement('tr');
    const celulaNome = document.createElement('td');
    celulaNome.textContent = usuario.name;
    const celulaCidade = document.createElement('td');
    celulaCidade.textContent = usuario.address.city;
    linha.appendChild(celulaNome);
    linha.appendChild(celulaCidade);
    corpoTabela.appendChild(linha);
  });
});

Exercício 5 — Buscador de Post Completo

⭐⭐⭐⭐⭐

O que você tem

<input id="input-id" value="1" placeholder="ID do post">
<button id="btn-buscar-post">Buscar Post</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const inputId = document.querySelector('#input-id');
  const botao = document.querySelector('#btn-buscar-post');
  const saida = document.querySelector('#saida');
  // seu código aqui
</script>

O que fazer

1. Mostre "Carregando..." antes do fetch.

2. Busque .../posts/<id>. Se !resposta.ok, mostre "Post não encontrado (status <status>)."

3. Se deu certo, mostre título + corpo do post.

4. Envolva tudo num try/catch pra erro de conexão.

Solução

botao.addEventListener('click', async () => {
  saida.textContent = 'Carregando...';
  try {
    const resposta = await fetch('https://jsonplaceholder.typicode.com/posts/' + inputId.value);
    if (!resposta.ok) {
      saida.textContent = 'Post não encontrado (status ' + resposta.status + ').';
      return;
    }
    const post = await resposta.json();
    saida.textContent = post.title + '\n\n' + post.body;
  } catch (erro) {
    saida.textContent = 'Erro de conexão: ' + erro.message;
  }
});

Checklist do Buscador:

✔ mensagem de "Carregando..."

✔ resposta.ok checado antes de usar os dados

✔ try/catch pra erro de rede

✔ os 3 estados (carregando/erro/sucesso) cobertos
