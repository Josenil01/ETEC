CSS Grid: A Matriz Perfeita

Grid permite criar colunas e linhas bidimensionais com precisão matemática. Domine o layout em grelha e construa interfaces complexas sem esforço.

1 Conceitos-Chave

Ao contrário do Flexbox (que opera num único eixo), o CSS Grid é bidimensional, controlando linhas e colunas simultaneamente.

  • display: grid inicia o container.
  • grid-template-columns define o tamanho e quantidade das colunas.
  • grid-template-rows define as linhas.
  • gap controla o espaçamento entre os itens.

A Unidade Fracionária (fr)

No Grid usamos muito a unidade fr (fração). Declarar grid-template-columns: 1fr 2fr; significa criar duas colunas, onde a segunda tem o dobro da largura da primeira!

Posicionamento Avançado

Ocupação de Espaço (Spanning)

Os itens não precisam de ficar presos numa só célula.

grid-column: 1 / 3; /* Ocupa 2 colunas */ grid-row: 2 / 4; /* Ocupa 2 linhas */

Áreas Nomeadas (Regions)

Pode desenhar o layout como "ASCII Art" atribuindo nomes às áreas com grid-template-areas e referenciando-as nos filhos com grid-area.

2. Exemplo Prático

O código base e o seu resultado visual. Repare como o item D se estende pelas colunas.

grid_exemplo.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Exemplo CSS Grid</title>
  <style>
    body {
      margin: 0; padding: 24px;
      font-family: Arial, sans-serif;
      background: #f4f4f4;
      display: flex; justify-content: center;
    }
    .grid-container {
      display: grid;
      grid-template-columns: 100px 1fr 100px;
      gap: 10px;
      width: min(95%, 720px);
      background: #fff;
      padding: 16px; border-radius: 12px;
    }
    .grid-item {
      display: flex; align-items: center; justify-content: center;
      color: #fff; font-weight: bold; height: 80px; border-radius: 6px;
    }
    .item-a { background: #1abc9c; }
    .item-b { background: #3498db; }
    .item-c { background: #e74c3c; }
    .item-d {
      background: #f1c40f; color: #333;
      grid-column: 1 / 4; /* Ocupa as 3 colunas */
    }
  </style>
</head>
<body>
  <div class="grid-container">
    <div class="grid-item item-a">A</div>
    <div class="grid-item item-b">B</div>
    <div class="grid-item item-c">C</div>
    <div class="grid-item item-d">D</div>
  </div>
</body>
</html>

4. Exercícios — Construtor de Layouts

Pratique a construção em grelha. Escreva o seu código no simulador e veja a magia acontecer.

Exercício 1 — A Grelha 2x2

⭐

Transforme o container numa grelha com 2 colunas iguais e 2 linhas iguais, aplicando um gap de 10px.

Exercício 2 — Galeria com MinMax

⭐⭐

Use a função repeat(3, minmax(200px, 1fr)) nas colunas para criar cards alinhados que não encolhem menos de 200px.

Exercício 3 — O Perfil (Grid Areas)

⭐⭐⭐

Faça um card de perfil usando grid-template-areas: "avatar nome" "avatar bio";. Atribua o grid-area correspondente a cada classe.

Exercício 4 — O Layout Clássico

⭐⭐⭐⭐

Construa um layout de página (Header, Sidebar, Main, Footer). O Sidebar deve ter 200px fixos, e o Header/Footer devem ocupar toda a largura superior e inferior.

Exercício 5 — Layout Responsivo Master

⭐⭐⭐⭐⭐

1. Crie o layout para telemóvel primeiro (1 coluna apenas).

2. Utilize uma Media Query @media (min-width: 600px).

3. Dentro da media query, reescreva o grid-template-areas para colocar a sidebar ao lado do conteúdo em telas grandes.

Desktop Areas:

"header header"

"sidebar main"

"footer footer"
