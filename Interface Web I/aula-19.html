Funções: As Fábricas de Ações

Até agora, todo código ficava solto dentro de um addEventListener. Hoje aprendemos a empacotar lógica em funções — pedaços de código reutilizáveis, com nome — e vamos usar isso numa calculadora de orçamento de verdade.

1 Conceitos-Chave

Uma função é uma fábrica: você entrega ingredientes (parâmetros), ela processa, e devolve um resultado (return).

  • function nome(param) { return valor; } — declaração de função, a forma clássica.
  • const nome = function(param) {...} — expressão de função, guardada numa variável.
  • const nome = (param) => {...} — arrow function, a forma mais curta e usada hoje em dia.
  • function saudar(nome = 'visitante') — parâmetro com valor default, usado quando nada é passado.

Sem Return, Sem Resultado

Uma função que não tem return devolve undefined — mesmo que ela mostre algo na tela com textContent. return é o que permite USAR o resultado depois, em outra parte do código.

Escopo e Closures

Escopo Local vs Global

Uma variável criada dentro de uma função só existe lá dentro — o resto do código nem sabe que ela existe.

function f() { let x = 1; } // x não existe fora

Closure — a Função que Lembra

Quando uma função é criada DENTRO de outra, ela "lembra" das variáveis de onde nasceu — mesmo depois da função de fora já ter terminado.

function criar() { let n = 0; return () => ++n; }

Vamos ver isso ao vivo no Playground: dois contadores independentes, criados pela mesma função.

2. Exemplo Prático: Calculadora de Orçamento

Três funções trabalhando juntas: uma calcula o subtotal, outra aplica desconto (com parâmetro default), e uma arrow function formata o preço.

calculadora_orcamento.html 
<style>
  .calculadora {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 12px;
    background: #fff; padding: 20px; border-radius: 12px; width: 300px;
  }
  button, #resultado { grid-column: 1 / 3; } /* Aula 14 */
  #resultado { white-space: pre-line; font-size: 13px; }
</style>

<div class="calculadora">
  <input id="preco" value="50">
  <input id="quantidade" value="12">
  <button id="btn-orcar">Gerar Orçamento</button>
  <p id="resultado">Preencha os dados</p>
</div>

<script>
  // 1. Declaração de função: calcula o subtotal
  function calcularSubtotal(preco, quantidade) {
    return preco * quantidade;
  }

  // 2. Parâmetro com valor default: sem desconto se nada for passado
  function aplicarDesconto(subtotal, percentual = 0) {
    return subtotal - (subtotal * percentual / 100);
  }

  // 3. Arrow function: formata um número como preço em reais
  const formatar = (valor) => `R$ ${valor.toFixed(2)}`;

  const inputPreco = document.getElementById('preco');
  const inputQuantidade = document.getElementById('quantidade');
  const botao = document.getElementById('btn-orcar');
  const resultado = document.getElementById('resultado');

  botao.addEventListener('click', () => {
    const preco = Number(inputPreco.value);
    const quantidade = Number(inputQuantidade.value);
    const subtotal = calcularSubtotal(preco, quantidade);

    let percentual = 0;
    if (quantidade >= 10) {           // Aula 17
      percentual = 15;
    } else if (quantidade >= 5) {
      percentual = 5;
    }

    const total = aplicarDesconto(subtotal, percentual);
    resultado.textContent = `Subtotal: ${formatar(subtotal)}\nDesconto: ${percentual}%\nTotal: ${formatar(total)}`;
  });
  </script>

Exercício 1 — Saudação Parametrizada

⭐

O que você tem

<input id="nome" value="Neo">
<button id="btn-saudar">Saudar</button>
<p id="saida">--</p>

<script>
  const inputNome = document.getElementById('nome');
  const botao = document.getElementById('btn-saudar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Crie function saudar(nome) que devolve (return) a frase "Olá, <nome>!". Chame-a no clique e mostre o resultado.

Dica

A função só devolve o texto — quem mostra na tela é o saida.textContent = saudar(...).

Solução

function saudar(nome) {
  return 'Olá, ' + nome + '!';
}

botao.addEventListener('click', () => {
  saida.textContent = saudar(inputNome.value);
});

Resultado esperado

Prévia

Olá, Neo!

Exercício 2 — Calculadora com Duas Funções

⭐⭐

O que você tem

<input id="a" value="4">
<input id="b" value="3">
<button id="btn-somar">Somar</button>
<button id="btn-multiplicar">Multiplicar</button>
<p id="saida">--</p>

<script>
  const inputA = document.getElementById('a');
  const inputB = document.getElementById('b');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Crie duas funções, somar(a, b) e multiplicar(a, b), e chame a certa em cada botão.

Dica

Não esqueça de converter inputA.value e inputB.value com Number() antes de calcular.

Solução

function somar(a, b) { return a + b; }
function multiplicar(a, b) { return a * b; }

document.getElementById('btn-somar').addEventListener('click', () => {
  saida.textContent = somar(Number(inputA.value), Number(inputB.value));
});
document.getElementById('btn-multiplicar').addEventListener('click', () => {
  saida.textContent = multiplicar(Number(inputA.value), Number(inputB.value));
});

Resultado esperado

12 (depois de clicar em "Multiplicar")

Exercício 3 — Convertendo para Arrow Function

⭐⭐⭐

O que você tem (já funciona)

<input id="numero" value="8">
<button id="btn-dobrar">Dobrar</button>
<p id="saida">--</p>

<script>
  function dobrar(numero) {
    return numero * 2;
  }

  document.getElementById('btn-dobrar').addEventListener('click', () => {
    const valor = Number(document.getElementById('numero').value);
    document.getElementById('saida').textContent = dobrar(valor);
  });
</script>

O que fazer

Reescreva a função dobrar como arrow function guardada numa const, mantendo o mesmo comportamento.

Dica

Formato: const dobrar = (numero) => numero * 2; — sem chaves nem return explícito, quando é uma linha só.

Solução

const dobrar = (numero) => numero * 2;

Exercício 4 — Consertando o Parâmetro Default

⭐⭐⭐⭐

O que você tem (com bug)

<input id="nome" value="Trinity">
<button id="btn-apresentar">Apresentar</button>
<p id="saida">--</p>

<script>
  // BUG: sem saudacao, o texto vira "undefined, Trinity!"
  function apresentar(nome, saudacao) {
    return saudacao + ', ' + nome + '!';
  }

  document.getElementById('btn-apresentar').addEventListener('click', () => {
    const nome = document.getElementById('nome').value;
    document.getElementById('saida').textContent = apresentar(nome); // só 1 argumento!
  });
</script>

O que fazer

O botão chama apresentar(nome) com só 1 argumento — mas a função pede 2. Corrija dando um valor default de 'Olá' para saudacao.

Dica

Mude só a linha da declaração: function apresentar(nome, saudacao = 'Olá').

Solução

function apresentar(nome, saudacao = 'Olá') {
  return saudacao + ', ' + nome + '!';
}

Resultado esperado

Prévia

Olá, Trinity!

Exercício 5 — Sua Própria Fábrica de Contadores

⭐⭐⭐⭐⭐

O que você tem

<p>Pontos Jogador 1: <span id="p1">0</span></p>
<button id="btn-p1">+1 ponto (J1)</button>
<p>Pontos Jogador 2: <span id="p2">0</span></p>
<button id="btn-p2">+1 ponto (J2)</button>

<script>
  // seu código aqui
</script>

O que fazer

1. Crie function criarContador() { let pontos = 0; return () => { pontos++; return pontos; }; }.

2. Chame criarContador() DUAS vezes, guardando cada resultado numa variável diferente.

3. No clique de cada botão, chame a função correspondente e mostre o resultado no span certo.

4. Confirme que os dois placares sobem de forma independente.

Solução

function criarContador() {
  let pontos = 0;
  return () => {
    pontos = pontos + 1;
    return pontos;
  };
}

const pontuarJ1 = criarContador();
const pontuarJ2 = criarContador();

document.getElementById('btn-p1').addEventListener('click', () => {
  document.getElementById('p1').textContent = pontuarJ1();
});
document.getElementById('btn-p2').addEventListener('click', () => {
  document.getElementById('p2').textContent = pontuarJ2();
});

Checklist da Fábrica:

✔ criarContador() retorna uma função

✔ chamada 2x, guardada em 2 variáveis

✔ cada botão usa a sua própria função

✔ placares sobem independente um do outro

Resultado esperado
