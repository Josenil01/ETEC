Arrays: Organizando Coleções

Uma variável guarda um valor. Um array guarda uma coleção inteira — e vem com métodos prontos para adicionar, remover, transformar e somar. Hoje construímos uma lista de compras de verdade.

1 Conceitos-Chave

Um array guarda vários valores numa única variável, em ordem.

  • const lista = ['a', 'b', 'c']; cria um array com 3 itens.
  • lista[0] acessa o primeiro item, e lista.length conta quantos existem.
  • lista.push(valor) adiciona no fim; lista.pop() remove o último.
  • const [a, b] = lista; — desestruturação: pega os primeiros itens direto em variáveis separadas.

Índice Começa em Zero

O primeiro item de um array é lista[0], não lista[1]. E o último item é sempre lista[lista.length - 1] — um erro clássico de iniciante é esquecer o - 1.

Os 4 Métodos que Todo Mundo Usa

forEach — roda algo pra cada item

lista.forEach(item => console.log(item));

map — transforma e devolve um NOVO array

lista.map(item => item * 2);

filter — mantém só quem passa num teste

lista.filter(item => item > 10);

reduce — junta tudo num único valor

lista.reduce((total, item) => total + item, 0);

2. Exemplo Prático: Lista de Compras

Um array vazio que cresce com push() e encolhe com pop() — e uma função (Aula 19) reaproveitada pra sempre redesenhar a lista com forEach.

lista_de_compras.html 
<style>
  .painel {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;
    background: #fff; padding: 20px; border-radius: 12px; width: 300px;
  }
  input, #resultado { grid-column: 1 / 3; } /* Aula 14 */
  #resultado { white-space: pre-line; font-size: 13px; text-align: left; }
</style>

<div class="painel">
  <input id="item" placeholder="ex: Leite">
  <button id="btn-adicionar">Adicionar</button>
  <button id="btn-remover">Remover Último</button>
  <p id="resultado">Lista vazia</p>
</div>

<script>
  const inputItem = document.getElementById('item');
  const botaoAdicionar = document.getElementById('btn-adicionar');
  const botaoRemover = document.getElementById('btn-remover');
  const resultado = document.getElementById('resultado');

  const lista = [];  // array vazio pra começar

  function renderizar() {                // Aula 19: função reutilizável
    if (lista.length === 0) {          // Aula 17
      resultado.textContent = 'Lista vazia';
      return;
    }
    let texto = '';
    lista.forEach((item, indice) => {         // Aula 20
      texto += (indice + 1) + '. ' + item + '\n';
    });
    resultado.textContent = texto + '\nTotal: ' + lista.length + ' item(ns)';
  }

  botaoAdicionar.addEventListener('click', () => {
    if (inputItem.value) {
      lista.push(inputItem.value);
      inputItem.value = '';
      renderizar();
    }
  });

  botaoRemover.addEventListener('click', () => {
    lista.pop();
    renderizar();
  });
  </script>

Exercício 1 — Primeiro e Último

⭐

O que você tem

<button id="btn-ver">Ver Primeiro e Último</button>
<p id="saida">--</p>

<script>
  const filmes = ['Matrix', 'Inception', 'Interstellar'];
  const botao = document.getElementById('btn-ver');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Mostre o primeiro (filmes[0]) e o último item do array, usando filmes.length para achar o índice do último.

Dica

O último item é filmes[filmes.length - 1].

Solução

botao.addEventListener('click', () => {
  const primeiro = filmes[0];
  const ultimo = filmes[filmes.length - 1];
  saida.textContent = 'Primeiro: ' + primeiro + ' | Último: ' + ultimo;
});

Resultado esperado

Prévia

Primeiro: Matrix | Último: Interstellar

Exercício 2 — Somar com Reduce

⭐⭐

O que você tem

<button id="btn-total">Calcular Total</button>
<p id="saida">--</p>

<script>
  const precos = [15, 30, 22, 8];
  const botao = document.getElementById('btn-total');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use precos.reduce(...) para somar todos os valores do array.

Dica

Formato: precos.reduce((total, preco) => total + preco, 0) — o 0 no final é o valor inicial do total.

Solução

botao.addEventListener('click', () => {
  const total = precos.reduce((total, preco) => total + preco, 0);
  saida.textContent = 'Total: R$ ' + total;
});

Resultado esperado

Prévia

Total: R$ 75

Exercício 3 — Filtrar Maiores de Idade

⭐⭐⭐

O que você tem

<button id="btn-filtrar">Filtrar Maiores</button>
<p id="saida">--</p>

<script>
  const idades = [15, 22, 17, 30, 12, 25];
  const botao = document.getElementById('btn-filtrar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use idades.filter(...) para pegar só as idades >= 18, e mostre o array resultante.

Dica

.join(', ') transforma o array filtrado numa string legível pra mostrar.

Solução

botao.addEventListener('click', () => {
  const maiores = idades.filter((idade) => idade >= 18);
  saida.textContent = maiores.join(', ');
});

22, 30, 25

Exercício 4 — Mapear para Maiúsculas

⭐⭐⭐⭐

O que você tem

<button id="btn-mapear">Deixar Maiúsculo</button>
<p id="saida">--</p>

<script>
  const nomes = ['neo', 'trinity', 'morpheus'];
  const botao = document.getElementById('btn-mapear');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use nomes.map(...) com .toUpperCase() para gerar um novo array com todos os nomes em maiúsculas.

Dica

map não muda o array original — ele devolve um NOVO array. Guarde o resultado numa variável.

Solução

botao.addEventListener('click', () => {
  const maiusculos = nomes.map((nome) => nome.toUpperCase());
  saida.textContent = maiusculos.join(', ');
});

Resultado esperado

Prévia

NEO, TRINITY, MORPHEUS

Exercício 5 — Desestruturando o Pódium

⭐⭐⭐⭐⭐

O que você tem

<button id="btn-podium">Mostrar Pódium</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const colocacao = ['Neo', 'Trinity', 'Morpheus', 'Switch', 'Tank'];
  const botao = document.getElementById('btn-podium');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

1. Desestruture os 3 primeiros com const [ouro, prata, bronze, ...resto] = colocacao;

2. ...resto (rest) junta automaticamente todo o restante num novo array.

3. Monte um texto com medalhas e mostre quantos ficaram no resto.

Solução

botao.addEventListener('click', () => {
  const [ouro, prata, bronze, ...resto] = colocacao;
  saida.textContent = `🥇 ${ouro}  🥈 ${prata}  🥉 ${bronze}\n(+${resto.length} outros: ${resto.join(', ')})`;
});

Checklist do Pódium:

✔ desestruturação com 3 nomes + resto

✔ medalhas 🥇🥈🥉 nas posições certas

✔ resto.length conta quem sobrou

Resultado esperado

Prévia

🥇 Neo 🥈 Trinity 🥉 Morpheus
(+2 outros: Switch, Tank)
