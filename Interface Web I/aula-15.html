JavaScript: Dando Vida à Página

Até aqui, HTML deu a estrutura e CSS deu a aparência. Agora entra o JavaScript — a camada que reage a cliques, muda conteúdo e transforma uma página parada numa experiência interativa.

1 Conceitos-Chave

HTML é o esqueleto da página, CSS é a roupa — e o JavaScript são os músculos: é ele quem faz a página reagir a alguma coisa (um clique, uma tecla, o carregamento).

  • <script> é a tag que insere JavaScript numa página HTML.
  • defer espera o HTML inteiro carregar antes de rodar o script (o mais recomendado quando o script fica no <head>).
  • async roda o script assim que ele terminar de baixar, sem esperar o resto da página — útil para scripts independentes (ex: analytics).
  • console.log() imprime valores no Console do navegador — a ferramenta nº 1 para depurar (e entender) o que o seu código está a fazer.

Abra o Console (F12)

Antes de continuar, abra as Ferramentas de Desenvolvedor (tecla F12 ou Ctrl+Shift+I) e clique na aba Console. É lá que os seus console.log() vão aparecer — e é lá também que o navegador mostra os erros quando algo no seu JavaScript está errado.

O Documento Vivo (DOM)

1. Selecionar um Elemento

Para o JavaScript conseguir "ver" uma tag HTML, primeiro é preciso guardá-la numa variável.

const titulo = document.getElementById('titulo');

2. Mudar o Conteúdo ou o Estilo

Com o elemento guardado, .textContent troca o texto visível, e .style troca a aparência — tudo isto sem recarregar a página.

3. Reagir a um Evento

Um addEventListener('click', ...) diz ao navegador: "quando isto for clicado, executa esta função".

Vamos explorar o DOM a fundo nas Aulas 22 e 23 — por agora, é só a ponta do iceberg.

2. Exemplo Prático

O código base e o seu resultado visual. Repare que o <script> fica no fim do <body> — assim, quando ele roda, o título e o botão já existem na página.

primeiro_script.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Meu Primeiro Script</title>
  <style>
    body {
      display: flex; flex-direction: column;
      align-items: center; justify-content: center;
      height: 100vh; margin: 0; gap: 20px;
      font-family: Arial, sans-serif;
      background: #f4f4f4;
    }
    h1 { color: #334155; transition: color 0.3s; }
    button {
      padding: 10px 20px; font-size: 14px; font-weight: bold;
      border: none; border-radius: 8px;
      background: #c026d3; color: #fff; cursor: pointer;
    }
  </style>
</head>
<body>
  <h1 id="titulo">Sistema Offline</h1>
  <button id="btn-ligar">Ligar Sistema</button>

  <script>
    const titulo = document.getElementById('titulo');
    const botao = document.getElementById('btn-ligar');

    botao.addEventListener('click', () => {
      titulo.textContent = 'Sistema Online!';
      titulo.style.color = '#16a34a';
      console.log('Botão clicado! Sistema iniciado.');
    });
  </script>
</body>
</html>

Exercício 3 — Reagindo a um Clique

⭐⭐⭐

O que você tem

<div id="caixa"></div>
<button id="btn-mudar">Mudar Cor</button>

<script>
  const caixa = document.getElementById('caixa');
  const botao = document.getElementById('btn-mudar');
  // seu código aqui
</script>

O que fazer

Adicione um addEventListener('click', ...) no botão. Dentro da função, mude o style.backgroundColor da caixa.

Dica

A função passada ao addEventListener só roda quando o clique acontece — é aí dentro que a cor deve mudar.

Solução

botao.addEventListener('click', () => {
  caixa.style.backgroundColor = '#22c55e';
});

Resultado esperado

Prévia

depois de clicar em "Mudar Cor"

Exercício 4 — Contador de Cliques

⭐⭐⭐⭐

O que você tem

<span id="contador">0</span>
<button id="btn-clicar">Clique Aqui</button>

<script>
  const contador = document.getElementById('contador');
  const botao = document.getElementById('btn-clicar');
  let cliques = 0;
  // seu código aqui
</script>

O que fazer

Já existe uma variável let cliques = 0;. A cada clique no botão, some 1 a ela e atualize o textContent do contador na tela.

Dica

Dentro do addEventListener: primeiro atualize a variável cliques, depois jogue o novo valor no textContent.

Solução

botao.addEventListener('click', () => {
  cliques = cliques + 1;
  contador.textContent = cliques;
});

Resultado esperado

Prévia 3

depois de 3 cliques

Exercício 5 — O Painel Completo

⭐⭐⭐⭐⭐

O que você tem

<h2 id="titulo">Painel Desligado</h2>
<span id="contador">Cliques: 0</span>
<button id="btn-painel">Ativar Painel</button>

<script>
  const titulo = document.getElementById('titulo');
  const contador = document.getElementById('contador');
  const botao = document.getElementById('btn-painel');
  let cliques = 0;

  botao.addEventListener('click', () => {
    // seu código aqui
  });
</script>

O que fazer

1. Mude o texto do título.

2. Mude a cor de fundo do document.body.

3. Some 1 ao contador de cliques e atualize o texto dele.

4. Registe cada clique no console.log().

Solução

botao.addEventListener('click', () => {
  titulo.textContent = 'Painel Ativo!';
  document.body.style.backgroundColor = '#581c87';
  cliques = cliques + 1;
  contador.textContent = 'Cliques: ' + cliques;
  console.log('Painel ativado, clique número', cliques);
});

Checklist do Painel:

✔ textContent

✔ style.backgroundColor

✔ cliques + 1 / textContent

✔ console.log

Resultado esperado

Prévia

Painel Ativo!
