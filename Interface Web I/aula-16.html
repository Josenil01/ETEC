Variáveis, Tipos e Conversões

Na aula passada, o JavaScript aprendeu a mexer na página. Agora vamos abrir a "caixa de ferramentas": o que ela guarda dentro das variáveis, e por que um número pode se comportar como texto se você não prestar atenção.

1 Conceitos-Chave

Uma variável é uma caixa com nome onde guardamos um valor. Mas o JavaScript também guarda, junto com o valor, o tipo dele — e isso importa mais do que parece.

  • let declara uma variável que pode mudar de valor depois.
  • const declara uma variável que nunca muda — use sempre que possível.
  • typeof valor pergunta ao JavaScript qual é o tipo daquele valor.
  • `Olá ${nome}` é um template literal — junta texto e variáveis usando crases e ${}, sem precisar do +.

A Armadilha do Input

Lembra do document.getElementById() da última aula? Pois é: todo valor que sai de um <input> chega como texto (string) — mesmo que pareça um número na tela. Se você somar dois desses direto, o JavaScript vai colar os textos em vez de somar. Vamos ver isso ao vivo já já.

Conversão: Implícita vs Explícita

Coerção Implícita (o JS decide sozinho)

O JavaScript tenta adivinhar o que você quis dizer — e nem sempre acerta.

'5' + 3 // 'e 53' (concatenou!) '5' - 3 // 2 (aí converteu...)

Conversão Explícita (você no controle)

Funções que convertem o tipo de forma clara e previsível.

Number('5') → 5 (number)
String(5) → "5" (string)
Boolean('') → false

Regra prática: se o valor veio de um formulário, converta ANTES de fazer contas com ele.

2. Exemplo Prático

Repare que input.value chega como texto — por isso o Number() é essencial antes de somar.

somador_simples.html 
<input type="text" id="valor" value="5">
<button id="btn-somar">Somar 10</button>
<p id="resultado">Resultado: --</p>

<script>
  const input = document.getElementById('valor');
  const botao = document.getElementById('btn-somar');
  const resultado = document.getElementById('resultado');

  botao.addEventListener('click', () => {
    const texto = input.value;          // sempre uma STRING
    const numero = Number(texto);        // conversão explícita
    resultado.textContent = `Resultado: ${numero + 10}`;
  });
  </script>

Exercício 1 — Declare e Mostre

⭐

O que você tem

<p id="saida">Clique no botão para ver os dados.</p>
<button id="btn-mostrar">Mostrar Dados</button>

<script>
  const saida = document.getElementById('saida');
  const botao = document.getElementById('btn-mostrar');
  // seu código aqui
</script>

O que fazer

Declare const nome, const idade e const ativo com os tipos string, number e boolean. No clique do botão, mostre os três no textContent de saida.

Dica

Pode juntar os três com + por enquanto — o jeito mais elegante (template literal) é o próximo exercício.

Solução

botao.addEventListener('click', () => {
  const nome = 'Neo';
  const idade = 25;
  const ativo = true;
  saida.textContent = 'Nome: ' + nome + ' | Idade: ' + idade + ' | Ativo: ' + ativo;
});

Resultado esperado

Prévia

Nome: Neo | Idade: 25 | Ativo: true

Exercício 2 — Saudação com Template Literal

⭐⭐

O que você tem

<input id="input-nome" value="Trinity">
<input id="input-cidade" value="Zion">
<button id="btn-saudar">Gerar Saudação</button>
<p id="saida">Aguardando...</p>

<script>
  // seu código aqui
</script>

O que fazer

Leia os valores dos dois <input> e monte uma frase usando template literal (crase + ${}), sem usar +.

Dica

Template literal usa crase (`), não aspas — e as variáveis entram dentro de ${...}.

Solução

const inputNome = document.getElementById('input-nome');
const inputCidade = document.getElementById('input-cidade');
const botao = document.getElementById('btn-saudar');
const saida = document.getElementById('saida');

botao.addEventListener('click', () => {
  const nome = inputNome.value;
  const cidade = inputCidade.value;
  saida.textContent = `Olá, ${nome}! Bem-vindo a ${cidade}.`;
});

Resultado esperado

Prévia

Olá, Trinity! Bem-vindo a Zion.

Exercício 3 — Convertendo pra Número

⭐⭐⭐

O que você tem

<input id="input-numero" value="5">
<button id="btn-dobrar">Dobrar</button>
<p id="saida">Resultado: --</p>

<script>
  const inputNumero = document.getElementById('input-numero');
  const botao = document.getElementById('btn-dobrar');
  // seu código aqui
</script>

O que fazer

O valor do input chega como texto. Converta com Number(), multiplique por 2, e mostre o resultado.

Dica

Curiosidade: só o + tem esse problema de concatenar — *, - e / já convertem sozinhos. Mesmo assim, converta explicitamente para não depender disso.

Solução

const saida = document.getElementById('saida');

botao.addEventListener('click', () => {
  const texto = inputNumero.value;
  const numero = Number(texto);
  saida.textContent = 'Resultado: ' + (numero * 2);
});

Resultado esperado

Prévia Resultado: 10

depois de clicar em "Dobrar" com 5

Exercício 4 — Detetive de Tipos

⭐⭐⭐⭐

O que você tem

<button id="btn-a">Tipo de "Neo"</button>
<button id="btn-b">Tipo de 2026</button>
<button id="btn-c">Tipo de true</button>
<p id="saida">Clique num botão.</p>

<script>
  const valorA = "Neo";
  const valorB = 2026;
  const valorC = true;
  // seu código aqui
</script>

O que fazer

Já existem 3 variáveis de tipos diferentes e 3 botões. Adicione um addEventListener em cada botão que mostra o typeof da variável correspondente.

Dica

São 3 listeners separados — um para btn-a, um para btn-b, um para btn-c.

Solução

const saida = document.getElementById('saida');

document.getElementById('btn-a').addEventListener('click', () => {
  saida.textContent = 'Tipo: ' + typeof valorA;
});
document.getElementById('btn-b').addEventListener('click', () => {
  saida.textContent = 'Tipo: ' + typeof valorB;
});
document.getElementById('btn-c').addEventListener('click', () => {
  saida.textContent = 'Tipo: ' + typeof valorC;
});

Resultado esperado

Prévia Tipo: string

depois de clicar em "Tipo de Neo"

Exercício 5 — Caçando o Bug da Coerção

⭐⭐⭐⭐⭐

O que você tem (já com o bug)

<input id="input1" value="5">
<input id="input2" value="10">
<button id="btn-somar">Somar</button>
<p id="saida">Resultado: --</p>

<script>
  const input1 = document.getElementById('input1');
  const input2 = document.getElementById('input2');
  const botao = document.getElementById('btn-somar');
  const saida = document.getElementById('saida');

  botao.addEventListener('click', () => {
    // BUG: isto concatena texto em vez de somar números!
    const resultado = input1.value + input2.value;
    saida.textContent = `Resultado: ${resultado} (tipo: ${typeof resultado})`;
  });
</script>

O que fazer

1. Rode o código (mentalmente ou no seu editor) e veja o resultado estranho.

2. Encontre a linha que soma input1.value + input2.value direto.

3. Corrija usando Number() nos dois valores antes de somar.

4. Confirme que o typeof do resultado virou "number".

Solução

botao.addEventListener('click', () => {
  const resultado = Number(input1.value) + Number(input2.value);
  saida.textContent = `Resultado: ${resultado} (tipo: ${typeof resultado})`;
});

Checklist da Correção:

✔ Number() no input1

✔ Number() no input2

✔ resultado é number, não string

✔ typeof confirmado no texto

Resultado esperado

Prévia Resultado: 15 (tipo: number)
