Laços de Repetição

Copiar e colar a mesma linha 10 vezes é coisa do passado. Hoje o JavaScript aprende a repetir tarefas sozinho — e vamos usar isso numa calculadora de parcelas de verdade.

1 Conceitos-Chave

Um laço (loop) repete um bloco de código várias vezes, sem você ter que escrever a mesma linha de novo.

  • for (let i = 0; i < n; i++) repete um número exato de vezes.
  • while (condição) repete enquanto a condição for verdadeira — útil quando você não sabe quantas voltas vai dar.
  • do...while é igual ao while, mas roda o bloco pelo menos uma vez antes de checar a condição.
  • for...of percorre os itens de um array direto, sem precisar de índice manual.

Cuidado com o Loop Infinito

Se você esquecer de atualizar a variável que controla a condição (o i++, por exemplo), o loop nunca termina e a aba do navegador trava. Sempre confira: a condição vai ficar falsa em algum momento?

Controlando o Loop

break — para tudo

Sai do loop imediatamente, mesmo que ainda faltassem voltas.

if (numero === alvo) break;

continue — pula só essa volta

Interrompe a volta atual e já passa para a próxima, sem sair do loop.

if (numero % 2 === 0) continue;

Reforçando a Aula 17

break e continue quase sempre vêm dentro de um if — é a condicional que decide QUANDO interromper o loop.

for...in percorre as chaves de um objeto — chega na Aula 21, quando falarmos de objetos.

2. Exemplo Prático: Calculadora de Parcelas

Grid organiza o formulário (Aula 14), if/else decide a taxa de juros (Aula 17), e um for gera cada linha de parcela sozinho.

calculadora_parcelas.html 
<style>
  .calculadora {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 12px;
    background: #fff; padding: 20px; border-radius: 12px; width: 300px;
  }
  button, #resultado {
    grid-column: 1 / 3; /* igual na Aula 14/17 */
  }
  #resultado { text-align: left; white-space: pre-line; }
</style>

<div class="calculadora">
  <input id="valor" value="1200">
  <input id="parcelas" value="6">
  <button id="btn-calcular">Calcular Parcelas</button>
  <p id="resultado">Preencha os dados</p>
</div>

<script>
  const inputValor = document.getElementById('valor');
  const inputParcelas = document.getElementById('parcelas');
  const botao = document.getElementById('btn-calcular');
  const resultado = document.getElementById('resultado');

  botao.addEventListener('click', () => {
    const valor = Number(inputValor.value);       // Aula 16
    const parcelas = Number(inputParcelas.value);

    let total = valor;
    if (parcelas > 3) {                        // Aula 17
      total = valor * (1 + 0.02 * parcelas);   // juros de 2% ao mês
    }
    const valorParcela = total / parcelas;

    let texto = parcelas <= 3 ? 'Sem juros:\n' : 'Com juros (2% a.m.):\n';
    for (let i = 1; i <= parcelas; i++) {       // Aula 18
      texto += `Parcela ${i}: R$ ${valorParcela.toFixed(2)}\n`;
    }

    resultado.textContent = texto;
  });
  </script>

Exercício 1 — Tabuada com For

⭐

O que você tem

<input id="numero" value="7">
<button id="btn-gerar">Gerar Tabuada</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const inputNumero = document.getElementById('numero');
  const botao = document.getElementById('btn-gerar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use um for de 1 até 10 para gerar a tabuada do número digitado, uma linha por vez (7 x 1 = 7, 7 x 2 = 14...).

Dica

Vá somando cada linha numa variável texto com += ... + '\n', e só no final coloque em saida.textContent.

Solução

botao.addEventListener('click', () => {
  const numero = Number(inputNumero.value);
  let texto = '';
  for (let i = 1; i <= 10; i++) {
    texto += numero + ' x ' + i + ' = ' + (numero * i) + '\n';
  }
  saida.textContent = texto;
});

Resultado esperado

Prévia

7 x 1 = 7
7 x 2 = 14
7 x 3 = 21
...

Exercício 2 — Contagem Regressiva com While

⭐⭐

O que você tem

<input id="inicio" value="5">
<button id="btn-contar">Contar Regressivo</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const inputInicio = document.getElementById('inicio');
  const botao = document.getElementById('btn-contar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use um while para contar de trás para frente até 1, e no final mostre "Lançar! 🚀".

Dica

O while continua enquanto o número for maior que 0 — não esqueça de diminuir a variável a cada volta.

Solução

botao.addEventListener('click', () => {
  let numero = Number(inputInicio.value);
  let texto = '';
  while (numero > 0) {
    texto += numero + '\n';
    numero = numero - 1;
  }
  texto += 'Lançar! 🚀';
  saida.textContent = texto;
});

Resultado esperado

Prévia

5
4
3
2
1
Lançar! 🚀

Exercício 3 — Somar Array com For...Of

⭐⭐⭐

O que você tem

<button id="btn-somar">Somar Preços</button>
<p id="saida">--</p>

<script>
  const precos = [10, 25, 8, 40];
  const botao = document.getElementById('btn-somar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use for...of para percorrer o array precos e somar todos os valores, mostrando o total.

Dica

for (const preco of precos) { ... } — dentro do loop, preco já é cada valor, sem precisar de precos[i].

Solução

botao.addEventListener('click', () => {
  let total = 0;
  for (const preco of precos) {
    total = total + preco;
  }
  saida.textContent = 'Total: R$ ' + total;
});

Resultado esperado

Prévia

Total: R$ 83

Exercício 4 — Pular Pares com Continue

⭐⭐⭐⭐

O que você tem

<input id="limite" value="10">
<button id="btn-listar">Listar Ímpares</button>
<p id="saida">--</p>

<script>
  const inputLimite = document.getElementById('limite');
  const botao = document.getElementById('btn-listar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use um for de 1 até o limite, com continue para pular os números pares, listando só os ímpares separados por vírgula.

Dica

numero % 2 === 0 é verdadeiro quando o número é par.

Solução

botao.addEventListener('click', () => {
  const limite = Number(inputLimite.value);
  let impares = [];
  for (let i = 1; i <= limite; i++) {
    if (i % 2 === 0) {
      continue;
    }
    impares.push(i);
  }
  saida.textContent = impares.join(', ');
});

Resultado esperado

Prévia

1, 3, 5, 7, 9

Exercício 5 — Catálogo com Alerta de Estoque

⭐⭐⭐⭐⭐

O que você tem

<button id="btn-catalogo">Gerar Catálogo</button>
<p id="saida" style="white-space:pre-line">--</p>

<script>
  const produtos = ['Notebook', 'Mouse', 'Teclado', 'Monitor'];
  const estoques = [3, 15, 8, 2];
  const botao = document.getElementById('btn-catalogo');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

1. Use um for com índice (0 até produtos.length - 1) — você precisa do índice pra acessar os dois arrays juntos.

2. Para cada produto, monte a linha: "1. Notebook (estoque: 3)".

3. Se estoques[i] < 5, acrescente " ⚠️ Estoque baixo" na mesma linha.

4. Mostre tudo em saida.textContent, uma linha por produto.

Solução

botao.addEventListener('click', () => {
  let texto = '';
  for (let i = 0; i < produtos.length; i++) {
    texto += (i + 1) + '. ' + produtos[i] + ' (estoque: ' + estoques[i] + ')';
    if (estoques[i] < 5) {
      texto += ' ⚠️ Estoque baixo';
    }
    texto += '\n';
  }
  saida.textContent = texto;
});

Checklist do Catálogo:

✔ for com índice (i)

✔ acessa produtos[i] e estoques[i]

✔ if de estoque baixo dentro do loop

✔ uma linha por produto

Prévia

1. Notebook (estoque: 3) ⚠️ Estoque baixo
2. Mouse (estoque: 15)
3. Teclado (estoque: 8)
4. Monitor (estoque: 2) ⚠️ Estoque baixo
