Flexbox: A Forja do Layout

Aprenda a distribuir espaço e alinhar elementos de forma dinâmica construindo a interface de um clássico: o Tetris.

1 Conceito Rápido

O Flexbox (Flexible Box Module) distribui espaço entre itens em um container, mesmo que seus tamanhos sejam desconhecidos ou dinâmicos.

  • display: flex ativa o contexto flexível.
  • Eixos: O alinhamento acontece no eixo principal (main) e no transversal (cross).
  • Direção: O eixo principal é definido por flex-direction (padrão é row).
  • Gap: A propriedade gap define o espaçamento exato entre os itens sem precisar de usar margens confusas.

O Paradoxo da Direção

Cuidado! Quando alteramos a direção para flex-direction: column, os eixos invertem-se. O justify-content passa a alinhar os itens na vertical (para cima e para baixo) e o align-items passa a atuar na horizontal (esquerda e direita).

Propriedades Essenciais

No Container (Pai)

  • • justify-content
  • • align-items
  • • flex-direction
  • • flex-wrap
  • • gap

Nos Itens (Filhos)

  • • flex (grow, shrink, basis)
  • • order
  • • align-self

Exemplo Prático

Veja como a teoria se traduz em código HTML e CSS puros, e o seu respectivo resultado no navegador.

exemplo.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Exemplo Flexbox</title>
  <style>
    body {
      margin: 0;
      padding: 20px;
      background: #f7f7f7;
      font-family: Arial, sans-serif;
    }
    .flex-container {
      display: flex;
      gap: 10px;
      justify-content: center;
      align-items: center;
      height: 200px;
      background: #eee;
      border-radius: 10px;
    }
    .flex-item {
      color: #fff;
      padding: 20px;
      border-radius: 8px;
      font-weight: bold;
      min-width: 40px;
      text-align: center;
    }
    .item-1 { background: #3498db; }
    .item-2 { background: #e74c3c; }
    .item-3 { background: #2ecc71; }
  </style>
</head>
<body>
  <div class="flex-container">
    <div class="flex-item item-1">1</div>
    <div class="flex-item item-2">2</div>
    <div class="flex-item item-3">3</div>
  </div>
</body>
</html>
