Você já usa addEventListener desde a Aula 15. Hoje conhecemos o objeto event por dentro, aprendemos a cancelar o comportamento padrão do navegador, e construímos um formulário de cadastro de verdade.

1 Conceitos-Chave

Toda função chamada por um evento recebe automaticamente um objeto — geralmente chamado de event — cheio de detalhes sobre o que aconteceu.

  • addEventListener('submit', ...) e 'keydown' — além do 'click' que você já conhece.
  • event.target diz QUAL elemento disparou o evento.
  • event.key diz qual tecla foi pressionada, em eventos de teclado.
  • event.preventDefault() cancela o comportamento padrão do navegador.

O Formulário que Recarrega Sozinho

Por padrão, um <form> recarrega a página inteira ao ser enviado — e todo o seu JavaScript "reinicia do zero". Se você quer controlar o envio com JS, o primeiro passo dentro do listener de 'submit' é sempre event.preventDefault().

Delegação de Eventos

O Jeito Antigo (Aula 22)

Um addEventListener em CADA item — se criar um item novo depois, ele não tem listener nenhum.

Delegação (o jeito esperto)

UM único listener no elemento PAI. Ele usa event.target pra descobrir qual filho foi clicado — funciona até pra filhos criados DEPOIS.

lista.addEventListener('click', (e) => { if (e.target.tagName === 'LI') ... });

Vamos ver isso ao vivo no Playground: um item novo, criado na hora, que já funciona sem código extra.

2. Exemplo Prático: Formulário de Cadastro

Um <form> de verdade, com preventDefault(), validação (Aula 17) e mensagem de sucesso ou erro.

formulario_cadastro.html 
<style>
  .painel {
    display: grid;
    grid-template-columns: 1fr;
    gap: 10px;
    background: #fff; padding: 20px; border-radius: 12px; width: 280px;
  }
</style>

<form id="form-cadastro" class="painel">
  <input id="nome" placeholder="Nome completo">
  <input id="email" placeholder="E-mail">
  <button type="submit">Cadastrar</button>
</form>
<p id="mensagem"></p>

<script>
  const form = document.querySelector('#form-cadastro');
  const mensagem = document.querySelector('#mensagem');

  form.addEventListener('submit', (event) => {
    event.preventDefault();          // impede o recarregamento!

    const nome = document.querySelector('#nome').value;
    const email = document.querySelector('#email').value;

    if (!nome || !email) {              // Aula 17
      mensagem.textContent = 'Preencha todos os campos!';
      mensagem.style.color = '#dc2626';
      return;
    }

    mensagem.textContent = 'Cadastro realizado: ' + nome + ' (' + email + ')';
    mensagem.style.color = '#16a34a';
    form.reset();
  });
  </script>

Exercício 1 — Contador de Cliques

⭐

O que você tem

<button id="btn-clicar">Clique Aqui</button>
<p id="saida">Cliques: 0</p>

<script>
  const botao = document.querySelector('#btn-clicar');
  const saida = document.querySelector('#saida');
  let cliques = 0;
  // seu código aqui
</script>

O que fazer

A cada clique, some 1 a cliques e atualize o texto.

Dica

Isso é praticamente igual ao que você já fez na Aula 15 — só trocando getElementById por querySelector.

Solução

botao.addEventListener('click', () => {
  cliques = cliques + 1;
  saida.textContent = 'Cliques: ' + cliques;
});

Exercício 2 — Campo Obrigatório com preventDefault

⭐⭐

O que você tem

<form id="form-nome">
  <input id="nome" placeholder="Seu nome">
  <button type="submit">Enviar</button>
</form>
<p id="saida">--</p>

<script>
  const form = document.querySelector('#form-nome');
  const saida = document.querySelector('#saida');
  // seu código aqui
</script>

O que fazer

No 'submit', use event.preventDefault(). Se o nome estiver vazio, mostre "Preencha o nome!"; senão, mostre "Enviado: <nome>".

Dica

A função do listener recebe o event como parâmetro: (event) => { event.preventDefault(); ... }.

Solução

form.addEventListener('submit', (event) => {
  event.preventDefault();
  const nome = document.querySelector('#nome').value;
  if (!nome) {
    saida.textContent = 'Preencha o nome!';
    return;
  }
  saida.textContent = 'Enviado: ' + nome;
});

Resultado esperado

Enviado: Neo

Exercício 3 — Capturar a Tecla Pressionada

⭐⭐⭐

O que você tem

<input id="campo" placeholder="Digite algo...">
<p id="saida">--</p>

<script>
  const campo = document.querySelector('#campo');
  const saida = document.querySelector('#saida');
  // seu código aqui
</script>

O que fazer

Use 'keydown' e event.key para mostrar qual tecla foi pressionada.

Dica

Teste apertar "Enter" ou uma letra qualquer — event.key devolve exatamente o nome dela.

Solução

campo.addEventListener('keydown', (event) => {
  saida.textContent = 'Tecla pressionada: ' + event.key;
});

Resultado esperado

Prévia

Tecla pressionada: Enter

Exercício 4 — Lista com Delegação

⭐⭐⭐⭐

O que você tem

<ul id="lista">
  <li>Item A</li>
  <li>Item B</li>
  <li>Item C</li>
</ul>
<p id="saida">Clique num item</p>

<script>
  const lista = document.querySelector('#lista');
  const saida = document.querySelector('#saida');
  // seu código aqui (UM listener só, no <ul>)
</script>

O que fazer

Coloque UM único listener em lista (não em cada <li>), e use event.target pra mostrar qual item foi clicado.

Dica

Confira se quem foi clicado é mesmo um <li>: event.target.tagName === 'LI'.

Solução

lista.addEventListener('click', (event) => {
  if (event.target.tagName === 'LI') {
    saida.textContent = 'Você clicou em: ' + event.target.textContent;
  }
});

Resultado esperado

Exercício 5 — Mini To-Do com Formulário e Delegação

⭐⭐⭐⭐⭐

O que você tem

<form id="form-tarefa">
  <input id="input-tarefa" placeholder="Nova tarefa...">
  <button type="submit">Adicionar</button>
</form>
<ul id="lista-tarefas"></ul>

<script>
  const form = document.querySelector('#form-tarefa');
  const inputTarefa = document.querySelector('#input-tarefa');
  const listaTarefas = document.querySelector('#lista-tarefas');
  // seu código aqui
</script>

O que fazer

1. No submit do form, use preventDefault(), crie um <li> (Aula 22) com o texto do input, e limpe o campo.

2. Coloque UM listener delegado em listaTarefas que alterna a classe 'concluida' no <li> clicado.

Solução

form.addEventListener('submit', (event) => {
  event.preventDefault();
  if (inputTarefa.value) {
    const li = document.createElement('li');
    li.textContent = inputTarefa.value;
    listaTarefas.appendChild(li);
    inputTarefa.value = '';
  }
});

listaTarefas.addEventListener('click', (event) => {
  if (event.target.tagName === 'LI') {
    event.target.classList.toggle('concluida');
  }
});
