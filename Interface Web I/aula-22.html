Manipulação do DOM I

Desde a Aula 15 você seleciona elementos que já existem no HTML. Hoje o JavaScript aprende a criar e destruir elementos do zero — e vamos construir uma lista de tarefas de verdade.

1 Conceitos-Chave

Até agora usamos getElementById. A partir de hoje, querySelector assume o posto — funciona igual, mas aceita qualquer seletor CSS, não só id.

  • document.querySelector('.classe') seleciona o PRIMEIRO elemento que bate com o seletor.
  • document.querySelectorAll('.classe') seleciona TODOS, numa lista que aceita .forEach().
  • elemento.classList.add/remove/toggle('nome') adiciona, remove ou alterna uma classe CSS.
  • document.createElement('li') cria um elemento do zero; pai.appendChild(filho) encaixa ele na página.

textContent vs innerHTML

textContent trata tudo como texto puro — sempre seguro. innerHTML interpreta HTML de verdade — se esse conteúdo vier de outro usuário sem filtro, é assim que ataques XSS acontecem. Regra: use textContent a não ser que precise mesmo inserir HTML.

Navegando e Removendo

elemento.remove()

Tira o elemento inteiro da página — não precisa mais dele, some.

elemento.parentElement

Acessa o "pai" de um elemento na árvore HTML — útil quando um botão precisa remover a linha inteira onde ele está.

botao.parentElement.remove();

Reforçando as Aulas 20 e 21

Criar um elemento pra cada item de um array (ou array de objetos) com forEach é um dos padrões mais usados de todo o JavaScript.

2. Exemplo Prático: Lista de Tarefas

Cada tarefa é criada do zero com createElement, marcada como concluída com classList.toggle, e apagada com remove().

lista_de_tarefas.html 
<style>
  .painel {
    display: grid;
    grid-template-columns: 1fr auto;
    gap: 8px;
    background: #fff; padding: 20px; border-radius: 12px; width: 300px;
  }
  #lista { grid-column: 1 / 3; list-style: none; padding: 0; margin: 10px 0 0; } /* Aula 14 */
  #lista li { display: flex; justify-content: space-between; gap: 6px; padding: 6px 0; border-bottom: 1px solid #f1f5f9; }
  .concluida { text-decoration: line-through; opacity: 0.5; }
</style>

<div class="painel">
  <input id="input-tarefa" placeholder="Nova tarefa...">
  <button id="btn-adicionar">+</button>
  <ul id="lista"></ul>
</div>

<script>
  const inputTarefa = document.querySelector('#input-tarefa');
  const botaoAdicionar = document.querySelector('#btn-adicionar');
  const lista = document.querySelector('#lista');

  function criarTarefa(texto) {
    const li = document.createElement('li');

    const span = document.createElement('span');
    span.textContent = texto;                    // nunca innerHTML aqui!

    const botaoConcluir = document.createElement('button');
    botaoConcluir.textContent = '✓';
    botaoConcluir.addEventListener('click', () => {
      span.classList.toggle('concluida');
    });

    const botaoRemover = document.createElement('button');
    botaoRemover.textContent = '✕';
    botaoRemover.addEventListener('click', () => {
      li.remove();
    });

    li.appendChild(span);
    li.appendChild(botaoConcluir);
    li.appendChild(botaoRemover);
    lista.appendChild(li);
  }

  botaoAdicionar.addEventListener('click', () => {
    if (inputTarefa.value) {
      criarTarefa(inputTarefa.value);
      inputTarefa.value = '';
    }
  });
  </script>

Exercício 1 — Selecionar por Classe

⭐

O que você tem

<h2 class="titulo">Título Original</h2>
<button id="btn-mudar">Mudar Título</button>

<script>
  const botao = document.querySelector('#btn-mudar');
  // seu código aqui
</script>

O que fazer

Use document.querySelector('.titulo') (seleção por CLASSE) para trocar o texto do título ao clicar.

Dica

Seletor de classe começa com ponto: '.titulo', não 'titulo'.

Solução

botao.addEventListener('click', () => {
  const titulo = document.querySelector('.titulo');
  titulo.textContent = 'Título Atualizado!';
});

Exercício 4 — Remover ao Clicar no X

⭐⭐⭐⭐

O que você tem

<ul id="lista">
  <li>Item 1 <button class="remover">✕</button></li>
  <li>Item 2 <button class="remover">✕</button></li>
  <li>Item 3 <button class="remover">✕</button></li>
</ul>

<script>
  const botoesRemover = document.querySelectorAll('.remover');
  // seu código aqui
</script>

O que fazer

Use botoesRemover.forEach(...) pra dar um clique a CADA botão, removendo o <li> pai dele.

Dica

Dentro do forEach, cada botao.parentElement é o <li> daquele botão específico.

Solução

botoesRemover.forEach((botao) => {
  botao.addEventListener('click', () => {
    botao.parentElement.remove();
  });
});

Resultado esperado

Prévia

Item 1, Item 3 (Item 2 removido após clicar no ✕)

Exercício 5 — Mini Gerador de Cards

⭐⭐⭐⭐⭐

O que você tem

<div id="container"></div>

<script>
  const pessoas = [
    { nome: 'Neo', cargo: 'The One' },
    { nome: 'Trinity', cargo: 'Hacker' },
    { nome: 'Morpheus', cargo: 'Capitão' }
  ];
  const container = document.querySelector('#container');
  // seu código aqui
</script>

O que fazer

1. Use pessoas.forEach((pessoa) => ...) (Aula 20+21: array de objetos).

2. Pra cada pessoa, crie um <div> (o "card"), um <h3> com o nome, e um <p> com o cargo.

3. Encaixe o h3 e o p dentro do card, e o card dentro do container.

Solução

pessoas.forEach((pessoa) => {
  const card = document.createElement('div');
  card.classList.add('card');

  const nome = document.createElement('h3');
  nome.textContent = pessoa.nome;

  const cargo = document.createElement('p');
  cargo.textContent = pessoa.cargo;

  card.appendChild(nome);
  card.appendChild(cargo);
  container.appendChild(card);
});

Checklist do Gerador:

✔ forEach sobre o array de objetos

✔ createElement pra div/h3/p

✔ appendChild encaixando tudo

✔ 3 cards aparecem na tela
