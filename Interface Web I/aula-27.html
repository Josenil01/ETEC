Módulos JavaScript

Até agora, todo o código de uma aula mora num arquivo só. Projetos de verdade dividem o código em vários arquivos — e é isso que os módulos ES organizam, com export e import.

1 Conceitos-Chave

Um módulo é um arquivo JavaScript que pode exportar pedaços de código pra outros arquivos importarem.

  • <script type="module" src="arquivo.js"></script> — carrega um arquivo COMO módulo (obrigatório pro import/export funcionar).
  • export function nome() {...} — export NOMEADO. Pode ter vários por arquivo.
  • export default ... — export PADRÃO. Só um por arquivo.
  • import { nome } from './arquivo.js'; (com chaves, nomeado) vs import nome from './arquivo.js'; (sem chaves, default).

Módulos Só Funcionam em Servidor

Diferente de scripts comuns, módulos ES não carregam abrindo o arquivo direto (file://) por questão de segurança do navegador. Por isso o Exemplo Prático de hoje não tem preview ao vivo — só funciona de verdade com Live Server, que você já usa.

Escopo Isolado

Cada módulo tem seu próprio "mundo"

Uma variável criada num módulo NÃO existe fora dele — mesmo sem let/const "vazando". Só o que é exportado fica visível.

Organização por responsabilidade

Um arquivo, uma responsabilidade: matematica.js só faz contas, ui.js só mexe no DOM. Isso facilita achar e reaproveitar código.

Import dinâmico

Existe também import(url), como uma função que devolve uma Promise (Aula 24) — vamos usar essa versão no Playground pra provar o escopo isolado sem precisar de servidor.

2. Exemplo Prático: Calculadora Modular (2 arquivos)

Um arquivo cuida da matemática, outro só importa e usa. Teste isso de verdade no seu editor com Live Server.

matematica.js 
// Dois exports nomeados
export function somar(a, b) {
  return a + b;
}

export function multiplicar(a, b) {
  return a * b;
}

// Um export default -- só pode ter UM por arquivo
export default function apresentar(nomeCalculadora) {
  return `Calculadora: ${nomeCalculadora}`;
}
index.html 
<button id="btn-calcular">Calcular</button>
<p id="resultado"></p>

<script type="module">
  import apresentar, { somar, multiplicar } from './matematica.js';

  const botao = document.querySelector('#btn-calcular');
  const resultado = document.querySelector('#resultado');

  botao.addEventListener('click', () => {
    resultado.textContent = apresentar('Neo') + ` — Soma: ${somar(4, 5)}, Multiplicação: ${multiplicar(4, 5)}`;
  });
  </script>
Prévia (não roda aqui — precisa de Live Server)

Calculadora: Neo — Soma: 9, Multiplicação: 20

4. Exercícios — Organizando o Código

Resolva os desafios abaixo no seu próprio editor, com Live Server ligado (módulos precisam de servidor). Cada card mostra o que você já tem, o que fazer, e como deve ficar o resultado.

Exercício 1 — Exportar e Importar Uma Função

⭐

O que você tem

// saudacoes.js
function saudar(nome) {
  return 'Olá, ' + nome + '!';
}
// seu código aqui: exporte "saudar"

// index.html
<script type="module">
  // seu código aqui: importe "saudar" e chame
</script>

O que fazer

Adicione export antes da função em saudacoes.js, e importe com import { saudar } from './saudacoes.js'; no HTML.

Dica

Não esqueça do type="module" na tag <script>.

Solução

// saudacoes.js
export function saudar(nome) {
  return 'Olá, ' + nome + '!';
}

// index.html
<script type="module">
  import { saudar } from './saudacoes.js';
  console.log(saudar('Neo'));
</script>

Resultado esperado

Prévia

Console: Olá, Neo!

Exercício 2 — Múltiplos Named Exports

⭐⭐

O que você tem

// validadores.js
function ehMaiorDeIdade(idade) { return idade >= 18; }
function ehEmailValido(email) { return email.includes('@'); }
// seu código aqui: exporte as duas

// index.html
<script type="module">
  // seu código aqui: importe as duas de uma vez
</script>

O que fazer

Exporte as duas funções, e importe as DUAS numa única linha: import { a, b } from '...'.

Dica

Separe os nomes por vírgula dentro das chaves.

Solução

// validadores.js
export function ehMaiorDeIdade(idade) { return idade >= 18; }
export function ehEmailValido(email) { return email.includes('@'); }

// index.html
<script type="module">
  import { ehMaiorDeIdade, ehEmailValido } from './validadores.js';
  console.log(ehMaiorDeIdade(20), ehEmailValido('a@b.com'));
</script>

Resultado esperado

Prévia

Console: true true

Exercício 3 — Convertendo para Export Default

⭐⭐⭐

O que você tem

// config.js
export function configuracaoPadrao() {
  return { tema: 'escuro', idioma: 'pt-BR' };
}
// seu código aqui: transforme em export default

// index.html
<script type="module">
  // seu código aqui: importe sem chaves, com outro nome
</script>

O que fazer

Troque export function por export default function, e importe SEM chaves, chamando de config (nome à sua escolha).

Dica

Import default pode ter QUALQUER nome — não precisa bater com o nome original da função.

Solução

// config.js
export default function configuracaoPadrao() {
  return { tema: 'escuro', idioma: 'pt-BR' };
}

// index.html
<script type="module">
  import config from './config.js';
  console.log(config());
</script>

Resultado esperado

Prévia

Console: {tema: "escuro", idioma: "pt-BR"}

Exercício 4 — Mini Projeto em 3 Arquivos

⭐⭐⭐⭐

O que você tem

// Tudo num arquivo só -- separe em 3:
// dados.js   -> só o array
// logica.js  -> só a função de busca
// index.html -> importa dos dois e usa

const produtos = ['Notebook', 'Mouse', 'Teclado'];

function buscarProduto(nome) {
  return produtos.find((p) => p === nome) || 'Não encontrado';
}

O que fazer

Divida em dados.js (exporta produtos), logica.js (importa produtos de dados.js, exporta buscarProduto), e index.html (importa de logica.js e usa).

Dica

Um módulo pode importar de outro módulo — não só do HTML. logica.js também usa import no topo.

Solução

// dados.js
export const produtos = ['Notebook', 'Mouse', 'Teclado'];

// logica.js
import { produtos } from './dados.js';
export function buscarProduto(nome) {
  return produtos.find((p) => p === nome) || 'Não encontrado';
}

// index.html
<script type="module">
  import { buscarProduto } from './logica.js';
  console.log(buscarProduto('Mouse'));
</script>

Resultado esperado

Prévia

Console: Mouse

Exercício 5 — Encontre o Erro Clássico

⭐⭐⭐⭐⭐

O que você tem (não funciona)

// utilidades.js
export function dobrar(numero) {
  return numero * 2;
}

// index.html -- o console mostra um erro de sintaxe!
<script>
  import { dobrar } from './utilidades.js';
  console.log(dobrar(21));
</script>

O que fazer

1. Abra o Console (F12) — o erro real diz algo como "Cannot use import statement outside a module".

2. Ache a causa: a tag <script> não diz que é um módulo.

3. Corrija com UMA palavra.

Solução

<script type="module">
  import { dobrar } from './utilidades.js';
  console.log(dobrar(21));
</script>

Checklist do Diagnóstico:

✔ abriu o Console e leu o erro real

✔ identificou a tag <script> sem type

✔ adicionou type="module"

✔ confirmou que "42" aparece no console

Resultado esperado

Prévia Console: 42
