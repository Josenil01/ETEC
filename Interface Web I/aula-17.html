Condicionais: Os Portões de Decisão

Até agora o código sempre fazia a mesma coisa. Hoje o JavaScript aprende a decidir: SE isto for verdade, faça aquilo — SENÃO, faça outra coisa. E vamos usar isso dentro de um projeto de verdade: uma calculadora de IMC.

1 Conceitos-Chave

Uma condicional testa se algo é verdadeiro ou falso, e escolhe qual bloco de código rodar.

  • if / else if / else testa condições em cadeia, uma de cada vez.
  • switch compara um valor com várias opções exatas.
  • === compara valor e tipo ao mesmo tempo (o == só compara o valor, convertendo tipos escondido).
  • && / || / ! combinam ou invertem condições.

Regra de Ouro

Lembra da coerção de tipos da Aula 16? 5 == "5" dá true porque o JavaScript converte um dos dois escondido. Use sempre === (e !==) para comparar — assim você sabe exatamente o que está a acontecer.

Qual Ferramenta Usar?

If / Else — para faixas e comparações

Quando a condição envolve maior/menor, ranges, ou várias variáveis diferentes.

if (idade >= 18) { ... }

Switch — para um valor bater exato

Quando você compara a MESMA variável com várias opções fixas.

switch (nota) { case 'A': ... }

Ternário — if/else de uma linha

Perfeito para escolher entre dois valores simples.

const msg = idade >= 18 ? 'Maior' : 'Menor';

Hoje vamos usar tudo isso dentro de um projeto real — Grid (aula 14) + DOM (aula 15) + conversão de tipos (aula 16) + condicionais.

2. Exemplo Prático: Calculadora de IMC

Um projeto de verdade: Grid organiza o formulário, DOM captura o clique, Number() converte os valores, e uma cadeia de if/else if decide a categoria.

calculadora_imc.html 
<style>
  .calculadora {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 12px;
    background: #fff; padding: 20px; border-radius: 12px; width: 280px;
  }
  button, #resultado {
    grid-column: 1 / 3; /* ocupa as 2 colunas, igual na Aula 14 */
  }
</style>

<div class="calculadora">
  <input id="peso" value="70">
  <input id="altura" value="1.75">
  <button id="btn-calcular">Calcular IMC</button>
  <p id="resultado">Preencha os dados</p>
</div>

<script>
  const inputPeso = document.getElementById('peso');
  const inputAltura = document.getElementById('altura');
  const botao = document.getElementById('btn-calcular');
  const resultado = document.getElementById('resultado');

  botao.addEventListener('click', () => {
    const peso = Number(inputPeso.value);      // Aula 16: converter
    const altura = Number(inputAltura.value);
    const imc = peso / (altura * altura);

    let categoria;
    if (imc < 18.5) {
      categoria = 'Abaixo do peso';
    } else if (imc < 25) {
      categoria = 'Peso normal';
    } else if (imc < 30) {
      categoria = 'Sobrepeso';
    } else {
      categoria = 'Obesidade';
    }

    resultado.textContent = `IMC: ${imc.toFixed(1)} — ${categoria}`;
  });
  </script>

Exercício 1 — Classificar Idade

⭐

O que você tem

<input id="idade" value="20">
<button id="btn-verificar">Verificar</button>
<p id="saida">--</p>

<script>
  const inputIdade = document.getElementById('idade');
  const botao = document.getElementById('btn-verificar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Converta o valor do input com Number() e use if/else para mostrar "Maior de idade" (>= 18) ou "Menor de idade".

Dica

Sem converter para número, a comparação "9" >= 18 pode não fazer o que você espera.

Solução

botao.addEventListener('click', () => {
  const idade = Number(inputIdade.value);
  if (idade >= 18) {
    saida.textContent = 'Maior de idade';
  } else {
    saida.textContent = 'Menor de idade';
  }
});

Maior de idade

Exercício 2 — Notas com Switch

⭐⭐

O que você tem

<select id="nota">
  <option>A</option>
  <option>B</option>
  <option>C</option>
  <option>F</option>
</select>
<button id="btn-ver">Ver Mensagem</button>
<p id="saida">--</p>

<script>
  const selectNota = document.getElementById('nota');
  const botao = document.getElementById('btn-ver');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use switch (selectNota.value) para mostrar uma mensagem diferente para cada nota (A = "Excelente!", B = "Muito bom", C = "Pode melhorar", F = "Precisa estudar mais").

Dica

Não esqueça do break; no fim de cada case, senão o switch continua para o próximo!

Solução

botao.addEventListener('click', () => {
  switch (selectNota.value) {
    case 'A':
      saida.textContent = 'Excelente!';
      break;
    case 'B':
      saida.textContent = 'Muito bom';
      break;
    case 'C':
      saida.textContent = 'Pode melhorar';
      break;
    default:
      saida.textContent = 'Precisa estudar mais';
  }
});

Resultado esperado

Prévia

Excelente!

Exercício 3 — Validar Login com &&

⭐⭐⭐

O que você tem

<input id="usuario" placeholder="usuário">
<input id="senha" placeholder="senha">
<button id="btn-entrar">Entrar</button>
<p id="saida">--</p>

<script>
  const inputUsuario = document.getElementById('usuario');
  const inputSenha = document.getElementById('senha');
  const botao = document.getElementById('btn-entrar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

Use && para checar se os DOIS campos foram preenchidos antes de mostrar "Login OK". Se faltar algum, mostre "Preencha usuário e senha".

Dica

Uma string vazia "" é "falsy" — if (inputUsuario.value && inputSenha.value) já resolve.

Solução

botao.addEventListener('click', () => {
  if (inputUsuario.value && inputSenha.value) {
    saida.textContent = 'Login OK';
  } else {
    saida.textContent = 'Preencha usuário e senha';
  }
});

Exercício 5 — Verificador de Acesso

⭐⭐⭐⭐⭐

O que você tem

<input id="idade" value="16">
<label><input type="checkbox" id="convite"> Tenho convite</label>
<button id="btn-verificar">Verificar Acesso</button>
<p id="saida">--</p>

<script>
  const inputIdade = document.getElementById('idade');
  const checkboxConvite = document.getElementById('convite');
  const botao = document.getElementById('btn-verificar');
  const saida = document.getElementById('saida');
  // seu código aqui
</script>

O que fazer

1. Converta idade com Number().

2. Se idade >= 18 E checkboxConvite.checked: "Acesso Liberado!".

3. Se idade >= 18 mas SEM convite: "Precisa de convite".

4. Caso contrário: "Acesso negado: menor de idade".

Solução

botao.addEventListener('click', () => {
  const idade = Number(inputIdade.value);

  if (idade >= 18 && checkboxConvite.checked) {
    saida.textContent = 'Acesso Liberado!';
  } else if (idade >= 18) {
    saida.textContent = 'Precisa de convite';
  } else {
    saida.textContent = 'Acesso negado: menor de idade';
  }
});

Checklist do Verificador:

✔ Number() na idade

✔ idade >= 18 && convite → liberado

✔ idade >= 18 sem convite → precisa convite

✔ menor de idade → negado

Resultado esperado

Prévia Precisa de convite
