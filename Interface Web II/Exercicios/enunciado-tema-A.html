Contexto e Missão

O Pokémon Challenge Festival chegou à sua cidade e a organização quer digitalizar o tradicional jogo da memória com cartas de papel. A ideia é simples: o participante informa seu nome, o jogo busca Pokémon reais da internet, o cronômetro começa e — ao final — a pontuação é salva no placar global para que todos possam ver quem é o Mestre Pokémon mais rápido.


Você foi designado como o Desenvolvedor Front-end responsável por criar o sistema completo: a tela inicial (coleta o nome do jogador), o tabuleiro do jogo (cartas com dados reais da PokéAPI, lógica de par, timer e pontuação) e a tela final com leaderboard global salvo no banco de dados via Neon.tech. Tudo em uma única página, sem recarregar.


Você possui como referência o projeto do Jogo de Memória Rick & Morty já desenvolvido em aula. Reutilize o conhecimento de lógica de cartas, fetch de API e manipulação de DOM — e agora vá além integrando o banco de dados e o sistema de pontuação por tempo.

Anatomia do Card e Dados da PokéAPI

Cada card possui frente (dados do Pokémon) e verso (padrão escondido). A virada é animada com CSS 3D. Os dados vêm do endpoint: https://pokeapi.co/api/v2/pokemon/{id}

🔙 Verso (card-verso) — padrão escondido
Fundo escuro (#0f172a) com um símbolo de Pokébola centralizado ou padrão decorativo. O verso é a face padrão ao iniciar o jogo — sem dados do Pokémon. CSS: backface-visibility: hidden.
🎴 Frente (card-frente) — dados do Pokémon
3 elementos obrigatórios:
• data.sprites.other['official-artwork'].front_default → imagem
• data.name → nome do Pokémon
• data.types[0].type.name → tipo principal

O tipo é exibido como uma badge colorida (.badge-tipo). CSS: transform: rotateY(180deg).

Exemplo de resposta da PokéAPI e extração dos campos:

// Fetch de um Pokémon pelo ID
const resposta = await fetch(`https://pokeapi.co/api/v2/pokemon/${idAleatorio}`);
const dados = await resposta.json();

const pokemon = {
  id:     dados.id,
  nome:   dados.name,
  imagem: dados.sprites.other['official-artwork'].front_default,
  tipo:   dados.types[0].type.name   // "fire", "water", "grass"...
};

Badges de tipo sugeridas — use as classes CSS a seguir (ou adapte com a paleta):

fire water grass psychic / ghost electric normal / outros

Fórmula de Pontuação

A pontuação é inversamente proporcional ao tempo: quanto mais rápido o jogador completa o jogo, mais pontos ganha. Use exatamente a fórmula abaixo — ela deve ser implementada no momento em que verificarVitoria() detecta que todos os pares foram encontrados.

// Fórmula obrigatória — tempoDecorrido em segundos inteiros
const pontuacao = Math.max(0, Math.floor(5000 - (tempoDecorrido * 10)));

// Exemplos:
// 30s → 5000 - 300 = 4.700 pts (muito rápido)
// 64s → 5000 - 640 = 4.360 pts (bom tempo)
// 200s → 5000 - 2000 = 3.000 pts (tempo moderado)
// 500s → Math.max(0, …) = 0 pts (proteção contra negativo)
💡 O tempo formatado para exibição na tela usa formatarTempo(segundos): const min = Math.floor(s/60).toString().padStart(2,'0'); const sec = (s%60).toString().padStart(2,'0'); return `${min}:${sec}`;

PokéAPI — Busca, Extração e Renderização dos Cards
Fetch assíncrono · IDs únicos aleatórios · Duplicação e embaralhamento
25 pontos

No script.js, implemente a função buscarPokemonsAleatorios(quantidade) que:

  • Gera quantidade IDs únicos e aleatórios entre 1 e 151 (Geração I). Use um Set para garantir unicidade:
async function buscarPokemonsAleatorios(quantidade) {
  const ids = new Set();
  while (ids.size < quantidade) {
    ids.add(Math.floor(Math.random() * 151) + 1);
  }
  const pokemons = [];
  for (const id of ids) {
    const resp  = await fetch(`https://pokeapi.co/api/v2/pokemon/${id}`);
    const dados = await resp.json();
    pokemons.push({ id: dados.id, nome: dados.name,
      imagem: dados.sprites.other['official-artwork'].front_default,
      tipo:   dados.types[0].type.name });
  }
  return pokemons;
}

Implemente a função renderizarCartas(pokemons) que:

  • Duplica o array e embaralha: [...pokemons, ...pokemons].sort(() => Math.random() - 0.5)
  • Limpa o #grid-cartas antes de renderizar
  • Para cada Pokémon, cria um elemento .card com a estrutura flip (frente + verso) e insere no grid
  • A frente exibe: <img> com a imagem oficial, <p> com o nome e <span class="badge-tipo"> com o tipo
  • O atributo data-key recebe o id do Pokémon — mesmo valor nas duas cartas do par
💡 A imagem official-artwork pode demorar para carregar. Adicione loading="lazy" na tag <img> e um placeholder de fundo no CSS enquanto carrega. O alt deve conter o nome do Pokémon.
🚫 Proibido usar listas fixas/hardcoded de Pokémon. O fetch à PokéAPI é obrigatório — assim como ocorreu com a API do Rick & Morty na referência. Projetos sem fetch real à PokéAPI terão nota zero na Tarefa 2.

Função iniciarJogo() — chamada pelo botão da tela inicial:

  • Valida que o campo de nome não está vazio. Se vazio: exibir toast de aviso e não prosseguir.
  • Armazena nomeJogador = document.getElementById('input-nome').value.trim()
  • Esconde a #tela-inicial (adicionar classe hidden)
  • Exibe o HUD com o nome do jogador em #hud-nome
  • Inicia o cronômetro com setInterval a cada 1000ms: incrementa tempoDecorrido e atualiza #hud-timer com formatarTempo(tempoDecorrido)
  • Chama buscarPokemonsAleatorios(10) e, ao receber os dados, chama renderizarCartas(pokemons)
  • Adiciona o listener de clique no #grid-cartas usando event delegation

Lógica de clique nas cartas (handler dentro de iniciarJogo):

  • Se bloqueado === true ou a carta já tem classe card-acertada ou card-virada: ignorar o clique
  • Adiciona card-virada na carta clicada
  • Se carta1 === null: armazena como primeira carta e aguarda
  • Se já existe carta1: armazena como carta2, define bloqueado = true e compara:
// Par CORRETO: mesmo data-key
if (carta1.dataset.key === carta2.dataset.key) {
  carta1.classList.add('card-acertada');
  carta2.classList.add('card-acertada');
  paresEncontrados++;
  document.getElementById('hud-pares').textContent = `${paresEncontrados} / ${totalPares}`;
  carta1 = carta2 = null;
  bloqueado = false;
  verificarVitoria();
} else {
  // Par ERRADO: aguarda 1s e vira de volta
  setTimeout(() => {
    carta1.classList.remove('card-virada');
    carta2.classList.remove('card-virada');
    carta1 = carta2 = null;
    bloqueado = false;
  }, 1000);
}

Função verificarVitoria():

  • Se paresEncontrados === totalPares: chama clearInterval(timer)
  • Calcula pontuacao com a fórmula obrigatória
  • Chama encerrarJogo(nomeJogador, pontuacao, tempoDecorrido)

Função reiniciarJogo() — botão "Jogar Novamente":

  • Reseta todas as variáveis de estado para os valores iniciais
  • Limpa o #grid-cartas e o #tabela-ranking
  • Esconde a #tela-final e exibe a #tela-inicial

Banco de Dados — Salvar Pontuação e Leaderboard
executarQueryNeon · INSERT · SELECT TOP 10 · Tela final
30 pontos

No script_db.js — motor de conexão (idêntico ao padrão da série):

const DATABASE_URL = "postgresql://usuario:senha@host/banco?sslmode=require";
const host = new URL(DATABASE_URL).host;
const neonHttpEndpoint = `https://${host}/sql`;

async function executarQueryNeon(querySQL, parametros = []) {
  try {
    const r = await fetch(neonHttpEndpoint, {
      method: 'POST',
      headers: { 'Neon-Connection-String': DATABASE_URL, 'Content-Type': 'application/json' },
      body: JSON.stringify({ query: querySQL, params: parametros })
    });
    if (!r.ok) throw new Error(await r.text());
    const dados = await r.json();
    return dados.rows;
  } catch (e) { console.error(e); return null; }
}

Funções exportadas do script_db.js:

  • export async function salvarPontuacao(nome_jogador, pontuacao, tempo_segundos) — executa INSERT INTO ranking (nome_jogador, pontuacao, tempo_segundos) VALUES ($1, $2, $3) RETURNING *. Retorna true se sucesso, false se erro.
  • export async function buscarLeaderboard() — executa SELECT * FROM ranking ORDER BY pontuacao DESC LIMIT 10. Retorna o array de registros ou [].
// INSERT
