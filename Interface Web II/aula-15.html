Aula 15: Enviando Formulários via POST

Na Aula 11 criámos e validámos formulários. Na Aula 14 construímos a arquitetura do servidor. Agora vamos ligar as duas pontas: criar a tela de Cadastro do nosso sistema e enviar os dados reais via fetch.

1. Ligando o Formulário ao Servidor

Na Aula 11 nós criámos formulários e validámos os dados no navegador. Na Aula 14, descobrimos como criar um Servidor Node.js para receber pedidos. Agora, vamos ligar as duas pontas construindo a tela de Cadastro do nosso projeto.

Quando alguém preenche o formulário de cadastro, o navegador não pode simplesmente recarregar a página e perder os dados. É preciso usar um método de envio (o fetch no JavaScript), especificar o endereço do destinatário (a URL do Servidor) e dizer como os dados estão empacotados (os headers e o body em JSON).

2. A Anatomia do Envio

1. Impedir o Envio Padrão
event.preventDefault()

Lembre-se da regra de ouro! Se não impedir o envio padrão do formulário HTML, a página recarrega e o seu código JavaScript nunca chega a enviar os dados via fetch.

2. Empacotando os Dados (JSON)
JSON.stringify(dados)

O servidor não entende objetos JavaScript puros. Precisamos transformar o nosso objeto (com os campos do formulário) numa string (texto puro) para viajar pela rede.

3. As Opções do Fetch
method: 'POST' Avisa que estamos a enviar dados novos, e não apenas a pedir informação.
headers A "etiqueta". Avisamos o servidor: 'Content-Type': 'application/json' para ele saber o que vem no corpo do pedido.
body O conteúdo exato do pedido (o resultado do nosso JSON.stringify).

A Ligação Front-to-Back

Camada 1 (Front-End) O Formulário (HTML)

O ficheiro index.html tem um formulário clássico. O id cadastro-form é o que vamos usar no JavaScript para interceptar o envio. Reparem: as classes auth-panel, auth-input e auth-btn são as mesmas das Aulas 13 e 14 — não precisamos reescrever o CSS a cada tela nova do projeto.

index.html
<div class="auth-panel">
    <form id="cadastro-form">
        <label>Nome:</label>
        <input type="text" id="input-nome" class="auth-input">

        <label>E-mail:</label>
        <input type="text" id="input-email" class="auth-input">

        <label>Senha:</label>
        <input type="text" id="input-senha" class="auth-input">

        <button type="submit" class="auth-btn">Criar Conta</button>
    </form>

    <div id="cadastro-output" class="hidden auth-output"></div>
</div>

Camada 1 (Front-End) O Envio dos Dados (cliente.js)

No ficheiro cliente.js, capturamos o evento submit, extraímos o .value dos campos e empacotamos tudo na propriedade body do fetch.

cliente.js
const form = document.getElementById('cadastro-form');
const output = document.getElementById('cadastro-output');

form.addEventListener('submit', async (event) => {
    event.preventDefault(); // 1. Bloqueia o recarregamento da página

    // 2. Lê os valores escritos pelo utilizador
    const nome = document.getElementById('input-nome').value;
    const email = document.getElementById('input-email').value;
    const senha = document.getElementById('input-senha').value;

    // Criamos o objeto que queremos enviar
    const novoUsuario = {
        nome: nome,
        email: email,
        senha: senha
    };

    output.classList.remove('hidden');
    output.innerHTML = '<div class="loader"></div> A criar a sua conta...';

    // 3. Envia o pedido POST para o localhost na porta 3000
    const resposta = await fetch('http://localhost:3000/api/cadastro', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json' // Avisa que o formato é JSON
        },
        body: JSON.stringify(novoUsuario) // Transforma o objeto em texto
    });

    // 4. Aguarda e lê o que o Servidor respondeu
    const dadosServidor = await resposta.json();
    output.innerHTML = `<strong>Servidor diz:</strong> ${dadosServidor.resposta}`;
});

Camada 2 (Back-End) O Ficheiro servidor.js

No código do servidor Node.js (que corre no seu terminal), recebemos o req.body, processamos o cadastro e respondemos via res.json().

servidor.js (Ficheiro Node.js/Express)
const express = require('express');
const cors = require('cors');

const app = express();
app.use(cors());
app.use(express.json()); // Essencial para o Express ler o JSON que vem no Body!

// Lista de utilizadores registados (na Aula 19 isto vira uma tabela real)
const usuarios = [];

// Rota para receber o cadastro
app.post('/api/cadastro', (req, res) => {

    // O req.body vai conter exatamente o objeto 'novoUsuario' que enviámos no Front-End!
    const { nome, email, senha } = req.body;

    console.log(`Novo cadastro recebido de: ${nome}`);

    let textoResposta = `Conta criada com sucesso! Bem-vindo(a), ${nome}.`;

    if (usuarios.some(u => u.email === email)) {
        textoResposta = 'Este e-mail já está cadastrado.';
    } else {
        usuarios.push({ nome, email, senha });
    }

    // Envia a resposta final em formato JSON
    res.json({ resposta: textoResposta });
});

app.listen(3000, () => console.log('Servidor local à escuta na porta 3000'));

4. Exercícios

Nível: Fácil

01

O Cabeçalho (Headers): No código do cliente.js (Etapa 2), escrevemos 'Content-Type': 'application/json'. Tente remover apenas essa linha do objeto headers do seu código local e faça um envio. O que acontece no servidor? (Dica: o servidor não vai conseguir ler o req.body corretamente sem esse aviso!).

Nível: Médio

02

Adicionando um Campo Extra: Adicione um elemento <select id="input-plano"> no seu HTML com opções (Gratuito, Pro). Modifique o cliente.js para ler também o valor desse select, adicioná-lo ao objeto novoUsuario e enviá-lo no POST. Verifique se no console.log() do servidor o plano escolhido aparece corretamente.

Nível: Desafio

03

E se a Rede Falhar? (Tratamento de Erros): No cliente.js, adicione um bloco try { ... } catch (erro) { ... } em volta de todo o processo de fetch.

Para simular uma falha (como o servidor estar desligado), pare o terminal do Node.js (Ctrl+C). Ao clicar no botão do Front-End, o catch deve disparar e imprimir no ecrã: "Não foi possível cadastrar. Servidor offline." com letras vermelhas.
